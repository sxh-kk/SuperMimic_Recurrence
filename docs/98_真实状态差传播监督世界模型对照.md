# 真实状态差传播监督世界模型对照

2026-10-29，实验前固定。96在尾撞/上升/首次板落地的H1动作响应上已出现局部进展，但H8响应仍近零；采后只读定位发现，即使模型直接读真实中间状态，正负分支的下一步差也未恢复。本次只检验增加真实不同状态响应传播监督，不改原SuperMimic模型、codec、数据或物理，不训练actor、不开放板BPTT。

## 固定来源与两臂

新入口`../scripts/local/fit_ollie_state_transport_wm.py`仅读93默认μ=.6冻结558条H8、原18锚点train/held分组；全部45条质量失败分支保留并标记，仍不是成功教师。94、96代码和原state/learning/contact模型代码保持，训练前另存这些文件的哈希。

两臂**直接复用96冻结的seed96初始权重和全部500组真实transition/pair批次**，不是复用96最终已训练权重。这样A只重现96既定目标，B仅新增transport项，减少额外初始化和采样差异；是否逐值重现96最终A目标权重会在采后核验，不能预先声称相等。

- A：`L_TF1 + .25 L_H1-action`，严格复用96目标；L_TF1从全部2976训练transition行的真实current state一步预测真实next state，原wheel权重.05；H1-action仅在每对同热anchor初态和首个实际正负action上定义，使用94冻结H1训练RMS尺度。
- B：`A + .25 L_true-state-transport`。

transport的输入是同anchor、同关节正负分支的**真实不同中间状态**`s_positive[k]`和`s_negative[k]`，k=1..7；两边使用相同的已保存后续action。预测各自一步后的板根世界VZ差，目标为真实`v_positive[k+1]−v_negative[k+1]`。这是有限的不同状态响应传播，**不是同状态action差分，也不是无穷小Jacobian**。首个脉冲之后两分支action逐值相同是采前强制核验条件。

目标先用float64真实数组相减，再转模型float32。每个六角色g、每个k的尺度独立固定为`max(RMS_train true_next_VZ_difference, .001 m/s)`，不读heldout；transport loss是六角色×七输入时刻共42组归一化平方误差均值，每组对paired samples取均值。没有free8或H8自由响应损失反向传播；k7的真实下一步差属于真实输入的一步监督，与自由H8端点损失区分记录。

## 预算、数据流和检查

沿96同初值、同TF1 batch64、同paired batch60（每角色10）、512³、Adam lr2e−4、clip1、最多500次成对更新。两臂梯度全部有限后才事务提交两个Adam，异常则两边权重和optimizer回滚，共同增加更新计数；总预算300秒、270秒后不接新pair。未满500次必须报告实际完成数，不追加拟合。

先MD预注册、CPU合约测试、inspect冻结初值/批次/来源/尺度/代码，再唯一正式采集式离线拟合。固定训练batch在0/100/250/500处单列TF1、H1和transport的梯度范数、加权后范数及三组cosine；不据此调权。保存计划与实际真实input覆盖，不把仅训练预测中间态说成已经训练真实中间态。
