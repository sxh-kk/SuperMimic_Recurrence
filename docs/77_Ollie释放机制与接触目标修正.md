## 原论文对释放和接触的实际结论

Nakashima与Chida的2021年研究使用二维板和规定运动的椭球脚，并非全身G1控制。其标准例先绕后轮快速转动，使板质心获得上升动量；两脚在尾触地前离开，之后后脚保持离板，前脚再接触以消除旋转、调平。该例尾地峰值只有6.9 N，后续前脚接触提供向下冲量，仍得到板的上升与调平。因此“尾撞后必须持续产生向上前脚力”不是这篇论文支持的通用条件。文中20°、足板静/动摩擦1/.8及规定脚运动均不同于本工程；18.7 N·s、2.22 m/s等参数也由作者明确限定为该研究的例子，不直接转成G1目标。[期刊全文，第3.1、3.2.4、3.3节](https://www.jstage.jst.go.jp/article/mej/8/5/8_21-00230/_pdf)

Shield、Johnson与Patel的2022年工作采用另一种接触模型：尾地为无摩擦、恢复系数e=.6的部分弹性冲击，足板为非弹性μ=1.6接触，轮地只是接触点；平面全身模型与简化点质量模型均需接触提示或已有解种子，空种子未找到可行解。它说明被动碰撞假设与初始化值得单独核验，不能把e=.6直接换算成MuJoCo的solref，也不能称为本片木板的标定结果。[作者全文，第VI节](https://www.andrew.cmu.edu/user/amj1/papers/RAL2022_Contact-implicit.pdf)

两篇模型给出的成功机制并不完全相同。可共同借鉴的是后脚施力、板绕支撑转动、适时卸载及后续接板的完整顺序，不能预先锁死为某一种持续接触或某个恢复系数。

## 12°、20°与原生摩擦锥能说明什么

[74号几何核验](74_鼻尾翘角与上提力方向核验.md)固定后轮支撑的纯pitch路径：12°板首次尾触地需板身抬头26.8379°，此时nose顶面倾角38.8379°。μ=.9的圆锥外包竖直力上界仍为负；20°固定内端下缘接点候选需板身抬头31.6166°，外包上界才为正。后者只是方向必要条件，不是实际机器人接触，更没有证明20°是必要或正确的板参数。

对作用于脚的单位法向量n、原生接触切向基t1/t2及dim3 pyramidal锥，板所受竖直力的精确归一化上界为：

```text
max(F_board,z / Fn) = −n_z + max(μ1 |t1_z|, μ2 |t2_z|)
```

纯pitch顶面倾角α的圆锥外包为`−cos(α)+μ sin(α)`，不能代替实际pyramidal接触基。12°、μ=.9在最有利切向基下需板pitch超过36.01°；在40°时有利基上界为+.09355，另一切向基可仍为−.11418。μ=.6则最有利顶面条件也需板pitch超过47.04°，高于旧60实际最大30.22°。这些限制针对顶面；有限nose内缘/端面可能产生不同法向，不能由顶面公式推出整个板不可能被上提。鞋横向姿态会影响有限边缘位置、滑动方向及腿部可达性，不会自动改变同一平面的摩擦锥方向。

[62号全身IK](62_Ollie前脚拖板全身可达性验证.md)尚未找到合格的正向带板接触姿态；局部移动脚得到正锥上界不是可执行姿态。[63号规定足运动夹具](63_Ollie尾撞释放与上提作用机制验证.md)也未实现腾空，不能当作机器人能力证明或全局不可行证明。[75号投影检查](75_视频翘角可辨识性检查.md)中12°/20°端点差3.44～7.50 px，小于既有8/12/12 px标注尺度；原相机和板姿态又依赖12°拟合，存在循环偏差。当前不从视频晋升20°，canonical保持12°。
