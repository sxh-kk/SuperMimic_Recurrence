# Ollie 空中数据世界模型梯度复核

## 实际结论

使用新增空中数据重新拟合的离线世界模型，在文档36完全相同的真实接触历史与动作基点上复核。**机器人根竖直速度的上升方向仍实际有效，可作为有限、短期、原生物理筛选下的课程信号；滑板动作梯度没有得到可信改善，不能恢复依赖板想象梯度的起跳优化。** 这不是已完成机器人起跳或Ollie的证明，也不是完整H8梯度可靠性的认证。

同一2.60 s原始动作基点，模型沿自身板VZ梯度改变目标，29维L2半径0.02 / 0.05 rad：模型预测板VZ增加 **0.003608 / 0.009062 m/s**，实际为 **−0.0000026 / +0.0000058 m/s**，几乎没有向上作用。此处板梯度范数相对真实割线放大 **109 / 132倍**，文档36在线第10轮模型为46 / 56倍，没有改善。

相同状态沿新模型的机器人根VZ梯度，预测增加 **0.006172 / 0.015469 m/s**，实际增加 **0.007364 / 0.018546 m/s**。三个实际历史、两个动作基点、两个半径的12次根VZ方向干预均实际向上；它们是同三个快照上的相关干预，不是12个独立成功回合。

## 与文档36一致的真实分支

实际入口为 `scripts/local/audit_ollie_wm_action_gradient.py`，新结果在 `logs/ollie_wm_gradient_audit_air_01/`。最小新增 `--offline-model` 选项，使air模型作为第三模型加载；原初始模型、在线第10轮模型、原始actor动作、第10轮actor动作和参考保持不变。

真实前缀仍来自 `logs/ollie_actor_video_timed_01/native_0000/rollout.npz`，参考SHA `941f748cf3b13edbcf60dd20f2db41810cee2cbd1e9b4dccba1e3b1d4b5a71f5`。完整前缀后复制mjData，保留warmstart和ctrl历史；2.60/2.76/2.88 s均仍有左右脚真实向上甲板支撑，轮接触依次4/4/3。前缀qpos/qvel最大误差均0，无根回写、板推力或外力。原质量、真实关节范围、扭矩、摩擦和物理步长均未改变。

与文档36输出的 **132个共同NPZ数组逐值误差均0**，包括真实快照、动作基点、原生±分支、旧两模型梯度。这同时核对了本轮周边代码编辑没有悄然改变比较对象。本轮全部138个NPZ数组有限，重复未扰动分支与原存档后继相同。

每个动作基点依旧测试29维逐关节±0.005 / ±0.02 rad，中央扰动被限位裁剪的关节从汇总排除，原始数据照存。真实分支20 ms、8个0.0025 s子步；另外每个模型执行自身robot Z/VZ与board Z/VZ方向L2半径0.02 / 0.05 rad。三个模型共144个方向干预，逐关节真实分支仍为696个，另12个重复/未扰动分支。没有为新增模型重复生成不同的接触初态。

## 机器人根梯度：可有限使用的范围

对较稳定的2.60 s原始动作，根VZ模型/原生范数比 **0.615 / 0.612**，cosine **0.740 / 0.734**，对应epsilon0.005 / 0.02；第10轮在线模型cosine0.773 / 0.765，新增air没有明显提高该方向一致性。

2.76 s原始动作附近真实接触对epsilon敏感，根VZ cosine为−0.150 / 0.157，不能解释为唯一平滑导数。换到同快照的第10轮actor动作基点，两个epsilon真实根VZ割线一致性高，air模型cosine **0.723 / 0.729**；此时可看到一个较可信的局部方向，但范数只有实际的0.382 / 0.377。

直接执行air模型根VZ方向，在2.76 s原始动作基点，预测 **+0.003995 / +0.010010 m/s**，实际 **+0.007518 / +0.018795 m/s**；2.88 s原始动作基点预测 **+0.002857 / +0.007153**，实际 **+0.004170 / +0.010876 m/s**。这些都是相对同快照基线的20 ms速度改变量，不能称为已有足够离地冲量。根VZ也不是整机COM VZ。

沿根Z方向的12次干预也都实际上升，但方向一致性比在线模型弱：epsilon0.02，2.60 s原基点cosine **0.265**（旧online0.579）；2.88 s第10轮actor基点 **0.105**（旧online0.340）。例如2.60 s半径0.02，模型预测根Z增加0.0786 mm，实际0.0317 mm。因此可以优先验证短期速度/冲量信号，不能只优化根位置而忽略模型独立位置残差的误差。

根Z/VZ小动作证据支持一个有限试验：固定已验证的准备前缀，在原生连续回放中检查短窗机器人上行动量，再决定是否延长。它不支持直接将H8模型展开当作真实跃起，也不保证落地、脚板接触或参考视频相似性。

## 滑板梯度：仍不可信

2.60 s原始动作的板VZ真实割线范数约 **0.00165 / 0.00136 (m/s)/rad**，air模型约0.180，放大109 / 132倍，cosine约 **0.000 / 0.006**。真实响应很小，是数值比值变大的原因之一；但直接方向干预也确认预测的上行动作实际近乎无效，而非仅凭一个比值判断。

2.76 s第10轮actor动作基点，air板VZ范数是真实的 **15.99 / 24.87倍**，旧online为9.79 / 15.23倍。2.88 s同基点，半径0.02时模型板VZ预测+0.001592、实际+0.002070 m/s，但半径0.05时预测 **+0.003995**、实际 **−0.007586 m/s**；跨幅度便反向，不能只挑小半径正例。

板Z也有明确反例：2.88 s原动作基点，预测板高度增加 **0.0405 / 0.1015 mm**，实际减少 **0.0378 / 0.0497 mm**。2.60 s虽然方向干预使板Z略增加，但仅约0.0002 / 0.0005 mm，远小于模型的0.0974 / 0.2443 mm，不能据此宣称向上梯度已修好。

air模型自动微分与其自身有限差分一致：两个VZ通道各epsilon汇总相对L2误差均小于 **0.00019**。本次仍未发现自动微分实现错误，问题在预测动力学与真实接触响应之间。有限差分是保持特定solver历史的条件割线，接触变化和限位边界始终照存，未当成普适光滑导数。
