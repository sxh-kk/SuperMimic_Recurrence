# 滑板全碰撞包络与连续腾空复核

2026-10-23。针对旧 PD 基线的“板离地”指标，新增独立原生 CPU 审计入口 `scripts/local/audit_ollie_saved_rollout.py`，实际复核 pilot 11、14、06。

**三组均没有满足“全板最低间隙 >5 mm、连续至少 40 ms、无板地接触力”的有效腾空窗口。** 旧 11 的 165 ms、14 的 220 ms 是多个轮高 / 无接触代理片段的累计值，不能称作一次连续全板腾空。审计保留了真实的微小间隙短片段，没有把“未达到验收标准”误写成“任意瞬间都没有离地”。

## 输入与精确控制重放

输入为各目录原始 `best_rollout.npz` 中实际 qpos、qvel、control、timestep，以及原 `best_contacts.csv`。这些是 generic PD 物理可行性基线，与原片 reference＋固定偏置＋反馈探针分开，不能将结果混为原视频动作复现或学习所得 Ollie。

每组输入包含 881 个原生 qpos / qvel 边界、880×29 实际控制，覆盖 2.2 秒。旧归档的 control 顺序是原生执行器顺序，不是直接假定为 G1 具名关节顺序。审计用相同模型、原始初始 qpos / qvel、初始 ctrl=0，在独立 `MjData` 中前进物理；之后只设置已记录的 29 个机器人目标，不再写入任何根或板位姿。

三组 **全部 qpos 和 qvel 边界的最大重放误差均严格为 0**。因此，本轮碰撞、接触力和离地高度针对的就是原先记录的实际运动，未通过重置、姿态覆盖或另换轨迹获得更正。

输入 NPZ SHA-256：

- 11：`7471bd48fd0f37114ca5ab5eb8856007334579dd72bd2f38b4939ea5f8c199d3`。
- 14：`5121f4003547a43bfdf4c26e500b3f45245194c424501a623cf22d2ab31bf605`。
- 06：`a73b1a6aad9de2b529d191c7c7f845507535a5be261ca03888541c366eed6f51`。

脚本默认要求 qpos / qvel 重放误差均不超过 `1e-9`，不满足则保存失败诊断并以非零状态退出，不认证原输入。提供明确的 `--control-order`、`--control-dt`、`--physics-dt` 和 `--initial-control`，其他归档必须按真实保存约定配置，不能猜测不存在的初速度或控制顺序。本轮原生物理步为 0.0025 秒，沿用共享连续窗口接口；当前入口明确限制该物理步长。

## 全包络、力和窗口口径

没有复制另一份轮底或板角公式。审计复用：

- `ContactObserver`：实际法向接触力、唯一轮几何计数、独立左右脚、板地 / 机器人地接触及穿透。
- `audit_ollie_timing.geometry_minimum_z`：真实旋转后的球、胶囊、圆柱和盒体在世界 Z 方向的最低支撑高度。
- `continuous_windows`：逐物理子步的连续窗口，累计时长和最长连续时长分别保存。

逐帧处理所有 **42 个可与地面碰撞的实际几何**，其中滑板 9 个：中心板、尾端、头端、前轴、后轴和四个轮圆柱。所有最低点保存在 NPZ / CSV；全板取这 9 个几何的最小值，而不是只取轮中心减半径。场景地面为 Z=0。另逐接触调用 `mj_contactForce`，按几何累加对地法向力，默认板对地总法向力低于 0.1 N 才归入无力支撑候选。

保留两种明确不同的窗口：

1. 无板地支撑力且全板正间隙超过 1 μm 的微小间隙片段，用于描述接触抖动和短暂分离，不当作成功。
2. 无板地支撑力且全板最低点高于 5 mm，并连续至少 40 ms 的有效腾空窗口。

还原旧代理时，严格读取原 CSV 的“轮高 >5 mm 且 board_ground=0”，不把旧指标悄悄改写成新定义。新 CSV 与原始时间逐点核对，接触记录包含初始化帧和每个 2.5 ms 子步。

## 实际结果

**pilot 11**：

- 最大全板最低间隙 **0.418790 mm**，在物理约 1.2175 秒，限制几何为 `board_tail`。
- 四个真实轮圆柱最低高度的峰值约 **29.941 mm**；这一较大的轮高不能代表板尾已明显离地。
- 旧代理累计 **165 ms**，分成 **17 段**，最长连续仅 **25 ms**；旧代理样本中 **84.85%** 时刻机器人已经触地。
- 按接触力与 >1 μm 全板间隙复核的最长片段也仅 **25 ms**；>5 mm / 连续 40 ms 的有效窗为 **0**。
- 尾端真实触地约从 **0.720 s** 开始，机器人首次触地 **0.9225 s**。最大穿透 **10.915 mm**。
- 全程最小板向上余弦 **-0.2810**，最终 **-0.06770**；最终板约侧滚 **93.88°**，双脚均未踩板，四轮也未落稳。它包含踩尾、短片段分离和侧翻，不能描述为完成 Ollie。

**pilot 14**：

- 最大全板最低间隙 **0.664189 mm**，约 1.2525 秒，限制几何同为 `board_tail`。
- 四个真实轮圆柱最低高度峰值约 **39.096 mm**。
- 旧代理累计 **220 ms**，分成 **20 段**，最长连续 **22.5 ms**；旧代理样本中 **88.64%** 时刻机器人已经触地。
- 无力支撑 / >1 μm 间隙最长 **22.5 ms**，有效全板腾空窗为 **0**。
- 机器人首次触地 **0.920 s**，最大穿透 **10.996 mm**；板最小向上余弦 **0.09887**，最终 **0.14389**，接近竖起而非水平接板。

**pilot 06**：

- 最大全板最低间隙仅 **0.012408 mm**，约 0.675 秒，限制几何为 `wheel_rear_right_collision`。
- 四轮最低高度峰值约 **19.790 mm**，仍与全板最低点差异很大。
- 旧代理累计 / 最长均仅 **2.5 ms**，只有一个物理子步；有效全板腾空窗为 **0**。
- 没有机器人触地，最大穿透 **8.997 mm**，最终板向上余弦约 **1.0**。它较好地返回站板，但没有满足弹板腾空要求，仍不能算完成 Ollie。

三个独立回合经当前 `outcome` 重新计算均为 **FAILED**。上述结果没有否定物理模拟本身：原控制可逐点重放；需要更正的是旧代理指标的名称、累计 / 连续口径以及对动作完成度的解释。

## 可复跑命令与产物

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
.venv/bin/python scripts/local/audit_ollie_saved_rollout.py \
  --rollout logs/ollie_pd_pilot_11/best_rollout.npz \
  --legacy-contacts logs/ollie_pd_pilot_11/best_contacts.csv \
  --out-dir logs/ollie/full_envelope_audit/verified_11
```

将 `11` 换成 `14` / `06` 可复跑另两组；输出目录必须不存在。本轮最终产物目录为：

- `logs/ollie/full_envelope_audit/verified_11/`
- `logs/ollie/full_envelope_audit/verified_14/`
- `logs/ollie/full_envelope_audit/verified_06/`

每个目录包含：

- `result.json`：原输入 / 旧 CSV / 审计代码哈希、精确重放误差、全板高度、旧 / 新连续窗口、板法向和真实 outcome。
- `geometry_and_forces.npz`：881 个子步采样时刻上，每个可碰地几何的最低 Z、对地法向力、几何名称 / ID、板列索引和板旋转。
- `per_geom_support.csv`：相同逐几何最低点与对地力的可读表格。
- `contacts.csv`：包含初始帧的逐物理步独立轮、脚、板、机器人地接触与穿透。
- `actual_replay.npz`：本次真实重放的 qpos / qvel、原始实际控制、控制顺序、物理 / 控制步长。

对照图 `logs/ollie/full_envelope_audit/whole_envelope_comparison.png` 已打开核对：四轮高度可达数十毫米时，板尾等最低点仍接近地面。右栏放大到毫米以下，避免只看轮高曲线误判。

另外制作了一份仅将原 11 最后一个保存 qpos 的 X 改动 1 mm 的**负测试副本**，未改动原输入。审计在 `expected_mismatch/` 正确报告 qpos 误差 `0.001`、`exact_replay_passed=False` 并非零退出，验证了失配不能静默通过。

三组全部实际重放、哈希 / 形状 / 有限性 / 时轴核验以及负测试通过；Ruff、格式检查和语法编译通过。后续应统一使用完整几何、真实力与连续窗口验收，再讨论踩尾、腾空、接板和最终站稳；不能继续把轮高或累计稀疏无接触时间单独作为 Ollie 成功指标。
