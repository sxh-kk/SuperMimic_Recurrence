# Ollie 全身QP姿态优先级固定对照

## 实际结论

文档48基线显示QP牺牲了关节姿态。本轮只测试一个明确修正：`--posture-priority strong`，提高关节加速度任务优先级；默认仍为`legacy`。**0.10 s和0.50 s通过原有准备质量门槛，但同参数2.76 s完整准备失败，身体1.475 s触地。** 已停止，没有继续调参、放宽门槛或生成已验证教师。

短窗改善有实测支持：0.50 s足平面偏差从基线 **63.16降到20.70 mm**，关节位置整体RMSE从 **0.341降到0.115 rad**，峰误差从1.909降到0.469 rad。但改善没有持续，不能把前0.50 s通过写成准备段已完成。

## 唯一配置差异与不变量

入口仍为 `scripts/local/track_ollie_whole_body_qp.py`。新增显式模式后：

- `legacy`：关节加速度残差尺度仍为腿/腰30、臂80、腕500 rad/s²。
- `strong`：腿/腰/臂统一3、腕10 rad/s²。

只有这组软任务权重改变。原tau上限、真实PD目标可达区间、腿200/腰80/臂腕30 rad/s²控制信赖范围、接触模型、QP硬方程、物理步长、8子步、20 ms目标保持和全部实际质量门槛均未改变。没有新增电机能力、外部力、根/板回写、仿真焊脚或直接执行qdd。

参考仍为v4：`data/ollie/tail_contact_upright_v4/joint_reference_50hz.npz`，SHA-256 `38243f1cc2c37ce1461817e83ced08410d90a332692a8c1d44dbb89dd54994e7`。本次只控制准备段，没有把其后的视频滑蹭/离尾阶段套用为固定站姿约束。

默认legacy的0.10 s回归结果在 `logs/ollie_whole_body_qp_legacy_regression_01/`：与已提交48基线 `smoke_05` 的state、qpos、qvel和实际action最大差均严格 **0**。新增姿态/任务诊断没有改变旧控制行为。

只采用这一组strong配置，严格按0.10→0.50→2.76 s顺序，前一段通过后才延长：

- 峰穿透2.932 mm、足平面偏差13.141 mm。
- 关节位置RMSE0.01392 rad、峰0.05169 rad。
- 左右足上表面支持90.2%/87.8%，4轮接地80.5%；通过原有短窗门槛。

**0.50 s**，`logs/ollie_whole_body_qp_strong_pilot_01/`：

- 最小upright0.99572，无身体触地，峰穿透4.789 mm、实际软关节越界0。
- 足高度误差2.410 mm、足平面偏差20.704 mm。
- root高度RMSE7.613 mm、最大误差18.104 mm。
- 关节位置RMSE0.11542 rad、峰0.46887 rad；关节速度RMSE0.58739 rad/s。
- 左右足支持98.0%/97.5%，末300 ms均100%；4轮接地91.0%。

**2.76 s**，`logs/ollie_whole_body_qp_strong_prep_01/`：

- `preparation_quality_passed=False`、`verified_teacher=False`、`ollie_success_certified=False`。

完整试验的前0.50 s与单独0.50 s的state/action/qpos/qvel逐值相同，延长后的失败不是换了初态或控制参数。

## 漂移出现的次序

不能仅凭一条失败轨迹数学证明某时刻已“不可恢复”；本轮没有另测恢复控制。能确认的是以下偏差随后未自行恢复：

1. **0.5325 s**：实际单关节最大参考误差首次超过0.5 rad。
2. **0.54 s**：QP近似足点首次有点因投影距离门槛而关闭，不等于整只真实足已失去接触。
3. **0.765 s**：足平面偏差首次超过40 mm；触地前最后一次≤40 mm是0.7625 s，此后没有回到合格范围。
4. **0.9725 s**：root-board XY超过0.2 m。
5. **1.1425 s**：upright跌破0.85。
6. **1.24/1.26 s**：QP右/左足的4个近似力点分别全部关闭；真实接触仍可能残留。1.40 s附近实际右脚仍有约14 N向上承重。
7. **1.475 s**：身体触地。

因此首先出现的是关节姿态/接触锚附近的累计漂移，随后COM与朝向任务误差快速扩大。不能把1.475 s的最终倒地当作之前都稳定，也不能把QP点关闭等同于真实接触消失。

## 预测任务与真实误差

新增日志直接保存每步期望/预测关节加速度、COM/root/足任务加速度以及真实逐子步关节误差。按0～0.50、0.50～1.00、1.00～1.46 s三个区间：

- 关节加速度软任务残差RMS：**10.13 / 15.16 / 29.11 rad/s²**。
- COM加速度任务残差RMS：**1.178 / 2.984 / 31.291 m/s²**。
- root角加速度任务残差RMS：**8.164 / 12.465 / 68.713 rad/s²**。
- 足平移加速度任务残差RMS：**0.240 / 0.704 / 4.246 m/s²**。
- 实际关节位置RMSE：**0.1147 / 0.2383 / 0.3379 rad**。

相比48的前0.50 s关节加速度任务残差49.21 rad/s²，strong确实减少了posture被牺牲，但未消除它。进入漂移后，原有运动学接触锚、物理接触和软目标之间的差异进一步扩大。上述结果不足以分离任务权重、近似足点激活、软接触与执行保持的因果份额，不据此再猜一组权重。

## 真实力矩、COP与独立回放

用保存的唯一初态和138个实际29维目标独立创建原生模型重放，全部控制边界qpos/qvel误差 **0**。所有state/action/qpos/qvel有限，轨迹SHA-256 `31b725e1d7bf315a0819b67e5bf20c27f06a901fbe75dc085c28508e74857090`。

全部QP的最大完整动力学残差1.1e-12、全部原始接触加速度约束残差1.1e-10、瞬时原生actuator force重建误差1.5e-14 N·m。没有以瞬时方程通过替代实际物理门槛。

独立回放另记录每个物理子步的实际tau，以及各20 ms内的实际平均tau与QP期望tau。0～0.50、0.50～1.00、1.00～1.46 s：

- 实际平均tau相对QP期望的整体RMS差 **0.595 / 0.881 / 0.758 N·m**。
- 逐子步瞬时tau差RMS **0.694 / 1.052 / 0.888 N·m**。
- 实际20 ms根加速度与QP瞬时预测的XYZ RMS差依次为 **[1.383,1.264,2.581] / [1.979,2.385,4.581] / [1.551,2.130,4.192] m/s²**。

这支持继续诊断接触/执行差异，但不能仅凭平均tau差较小就认为预测接触力正确。

COP使用**真实contact force**转world后、按向上竖直力加权，再转为板局部XY；脚侧只取真实top surface支持，轮/板地面另算。以各时刻±10 ms内有效样本平均：

- **0.10 s**：足COP约[−0.0519,+0.0028] m，地面COP[−0.0496,+0.0053]。
- **0.50 s**：足COP[−0.0557,−0.0148]，地面[−0.0618,+0.0020]。
- **0.70 s**：足COP[−0.0079,−0.0494]，地面[−0.0078,−0.0490]。
- **1.00 s**：足COP[−0.0200,−0.0664]，地面[−0.0193,−0.0480]。
- **1.20 s**：足COP[−0.0714,−0.0570]，地面[−0.0988,−0.0425]。
- **1.40 s**：左脚无支持，足COP移至后尾侧约[−0.3335,+0.0186]，右脚仅约14.3 N；这不是稳定的尾脚起跳支持。

COP是动态接触量，不能要求脚COP与地面COP每个时刻相等，也不能把单点抖动或少量剩余力当作支撑稳定。保存的无有效COP时刻有独立有效mask，未用缺失值伪造位置。
