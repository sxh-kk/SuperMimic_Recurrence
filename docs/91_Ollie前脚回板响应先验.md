# Ollie前脚回板响应先验

2026-10-29，首次执行前固定。90真实整板飞行77.5 ms，但右脚3.2775 s已有top>1 N时左脚仍无top；板3.3400 s右后轮先接地，左脚直到3.4425 s才承重，空中双top仍0。该完整回合严格FAILED，不能把晚到的双支撑算空中接板。

本轮仅构造一个小步真实响应动作先验，供后续重新线性化或原生候选探索。SuperMimic仍为下游学习路线；没有策略训练、世界模型训练或64轮搜索。原12°板、默认足板μ=.6、29PD、力矩、质量/惯性、重力及原严格v3保持不变。

## 保存轨迹的机械方向依据

原90在3.10 s左foot site的板系坐标为[.17767,.09274,.08744] m，3.26 s为[.18182,.14013,.00343] m，偏板+Y一侧；82/86在3.26 s左site Y分别约.13131/.17020 m。site只是几何点，实际顶面承重另用原Observer逐接触分类。

固定保存root/board姿态，原生FK和site Jacobian表明：90左髋pitch的板Y局部导数3.10/3.26 s约+.55905/+.39783 m/rad，负方向主要把前脚收向−Y；左髋roll/yaw主要联动板X与脚朝向，膝和右腿有助于控制高度和整体动量变化。左踝pitch在2.90～3.10 s目标正余量仅约.001～.014 rad，踝roll多时刻已在原target下限，因此本轮不把它们当作未裁剪的对称响应列。

这些仅是条件局部几何方向，不是IK可行性证明，也不保证PD目标变化等同实际关节位移。3.26 s的site Y到本轮.07 m目标相差70.13 mm；前四左腿关节各±.015 rad的局部线性Y变化外包仅约9.92 mm。本轮不预称一个小步足以完成整个横向回收。
