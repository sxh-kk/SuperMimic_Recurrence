# 真实中间状态一步监督世界模型对照

2026-10-29，实验前固定。本次继续SuperMimic原人板动力学网络和codec，只修改独立实验入口的数据取样与监督项，不训练actor、不开放板BPTT、不修改原物理或晋升失败教师。

## 94数据流的只读审计

94的`state_loss`调用`rollout(model, states[:,0], actions)`，自由递推每步都对真实state1..8计算误差，**但没有把真实中间state1..7作为独立模型输入**。模型仍会见到自己的预测中间状态，因此不能说“只训练了初始时刻”；缺少的是密集真实状态条件下的一步映射。

93训练372条分支的真实state0共有12个唯一初态（全部18锚点另6个留出）；训练state0..7共有2976行、2567个唯一state92，其中2555个真实中间输入不等于任何训练初态。逐步唯一数为`[12,366,366,366,366,366,366,366]`；初态state/action组合366个，全部真实一步state/action组合2921个。留出186分支有6个唯一初态、1488个真实一步输入行/1287个唯一state；全部558分支为18个初态、4464输入行/3854个唯一state。

审计为float64数组逐值`np.unique(axis=0)`，没有优化或仿真；记录`logs/ollie_phase_response_wm_01/true_intermediate_state_audit.json`，SHA256 `e6d7e47de8bdc26a290c5dd876a103f25e562f57a2e54b23dd7c3f2c8a5c8b52`。这支持补充中间真实状态监督；“状态Jacobian收缩或记住相位”仍是待验证解释，不能仅凭初态数量定因果。

## 唯一预注册对照

入口`../scripts/local/fit_ollie_transition_response_wm.py`，唯一数据仍为93默认μ=.6冻结558条H8，不混72的μ=.9；原18锚点整组train/held划分保持。372训练分支全部8步展开为2976条真实一步transition：`(s[b,k],a[b,k],s[b,k+1]), k=0..7`。45条原质量失败分支保留并标记，不当教师。

- `tf1_only = L_TF1`：模型直接读每条真实current state和对应实际action，一步预测真实next state，使用原归一化error-vector，wheel最后8项权重.05。
- `tf1_plus_response = L_TF1 + .25 L_response_H1`：H1响应为同热初态、首个实际正负动作的板根世界VZ预测差，对应真实float64正负差；六采样角色等权。尺度严格读取94已冻结的训练组H1 RMS（floor .001 m/s），不根据96留出重新估计。

没有free8损失或H8响应反向传播。后7步两分支真实状态已经不同，即使动作相同，也不能把它们称作同状态action差分；它们仅作为各自真实current→next的TF1监督。H1 paired仍只在原anchor state0上定义。

seed96、同初值/同预先保存批次；TF transition batch64从2976行采样，paired batch60每角色10对；512³网络、Adam lr2e−4、梯度范数上限1、最多500对更新。两臂先计算所有梯度，再事务提交两个Adam，异常回滚双方权重/optimizer，计数共同增加。总预算300秒，270秒后停止接新pair，保存实际更新数；不追加训练。训练前冻结数据/旧共享实现/新入口/初值/批次/尺度哈希，记录计划与实际真实input覆盖。

固定训练batch在0/100/250/500对更新处记录TF1与H1-response梯度范数和cosine，.25加权前后分开；不依据诊断调参。留出不参与尺度、batch、停止、权重或checkpoint选择。

## 验收和解释范围

最终训练/留出仍从每个原anchor自由展开H8，报告H1/H8板位置/速度每轴及向量误差、真实paired boardVZ的RMSE/zero-response/gain/sign，按总体、六角色、tail/air/landing记录。沿用94全部门槛，**不会因为训练只用H1便删除H8验收**。独立CPU以weights-only读回两份权重、核500对更新和批次哈希，并复算相同指标；CPU只评估、不训练。

与94横比时同时改变真实input取样、response训练时域/权重及seed，不能把差异单独归因为TF1。TF1本身也可能递推误差累积，H1局部拟合改善不保证H8可用。93仍无空中双足catch与稳定落地教师，即使局部指标通过仍actor0、板BPTT关闭。

## 梯度诊断与真实状态差的传播

固定训练batch，按“TF1梯度范数 / .25加权后的H1响应梯度范数 / cosine”记录：初始化`.01936/.01002/−.00077`，100次`.39150/.12977/+.05710`，250次`.42320/.10840/−.00606`，500次`.32002/.16196/+.06750`。H1响应加权前范数另存`gradient_diagnostics.json`；未根据这些值调整.25系数。

采后仅对已保存最终权重作探索性CPU定位：把每对真实中间state+/state−和对应相同后续action直接送模型做一次step，比较输出差与真实next-state差。k≥1输入状态本就不同，所以该量叫**真实不同状态的一步响应传播**，不是同状态action差分，也不是无穷小Jacobian。

实验臂留出这一传播在H2对应一步的gain仅`.05069`、符号率44.44%；H3 gain`−.35408`；H8对应一步gain`.13295`、RMSE`.094399 m/s`，劣于零差`.042145`。因此即使直接给真实中间状态，局部差分传播也没有可靠恢复；当前H8失败不能只归于自由rollout离开真实状态分布。此分析保存在`exploratory_native_state_transport.json`，标为采后探索，没有触发新增训练或门槛变更，也没有单凭此结果宣称机制已定因果。
