# 视频翘角可辨识性检查

**现有单目标注、固定相机与板参考不足以确定真实翘角为 12° 或 20°。** 两种假设在所查帧的端点投影差均小于既有目视标注不确定度。当前检查只给出条件敏感性，没有重新拟合或校准模型。

## 固定输入与端点定义

入口为 `scripts/local/check_ollie_kick_reprojection.py`，结果保存在 `logs/ollie_kick_reprojection_01/result.json`。输入文件路径及 SHA256 均写入结果：

- [13 号记录](13_板图案追踪与三维拟合记录.md)中的原 `manual_board_landmarks.json`，仅取原始帧 119、128、185；头尾点仍为原目视圆端近似中心，标注尺度分别为 **8、12、12 px**。
- 原 `board_reference_v3/fitted_source_trajectory.npz` 中相同源帧的共同世界板位姿，没有改用新参考或重新求姿态。
- 原 `body_world_raw.npz` 的固定 `K_fullimg`，以及原 `data/ollie/common_world.json` 的相机到共同世界变换；内参与外参都未优化。
- 原被动板 XML，以及保留原 inner-lower 附件点的 20° 独立几何假设。编译前明确切换 `MjSpec` 的 Euler/quat 替代表示，并核对编译后旋转确为 ±20°，避免旧无效候选仅写 quaternion 而仍沿用 Euler 的问题。

两种模型都用编译后 `geom_center + geom_rotation × [外端符号×halfLength,0,0]` 得到有限端面中心线点，**没有使用 top corner 或碰撞包络极值**。

12° 模型尾/头中心线点为 `[-/+0.400645151,0,0.025640525] m`；20° 模型为 `[-/+0.395072083,0,0.042039243] m`。固定附件点误差小于 `10⁻¹² m`。20° 假设使每端向板中心缩约 5.573 mm、升约 16.399 mm；未改 canonical 文件，也没有进行物理积分。

## 实际像素敏感性

以下顺序均为尾端 / 头端，数值是同一旧板位姿和相机下 20° 相对 12° 的二维投影位移模长：

- 帧 **119**：**3.440 / 4.077 px**；相对原 8 px 标注尺度为 **0.430 / 0.510**。
- 帧 **128**：**7.164 / 6.625 px**；相对原 12 px 尺度为 **0.597 / 0.552**。
- 帧 **185**：**7.504 / 6.858 px**；相对原 12 px 尺度为 **0.625 / 0.571**。

最大条件位移为 7.504 px，最大相对标注尺度为 0.625。上述“标注尺度”只是当时指定的目视工程不确定度，不是经过统计校准的高斯标准差；这些比值不能转成置信水平或模型选择概率。

作为剩余拟合冲突的背景，固定 12° 模型在帧 128 的两端标注残差约 26.75 / 21.12 px，在帧 185 为 25.24 / 31.98 px，已大于本次更改角度带来的位移。脚遮挡、近似圆端中心、板姿态/图案漂移及相机尺度误差仍没有在此得到独立分离。

## 能与不能据此判断的事

本次结果说明：在旧参考位姿不变的条件下，翘角从 12° 改为 20° 对这三个源帧的投影影响不足以明显超过当前标注尺度。因此现有证据不足以从视频确定实际翘角，也不能据此排除任一假设。

旧板位姿拟合本就依赖原 12° 板几何、假设的 0.8013 m 长度、图案尺寸、相机/地面估计，并使用了这批相同端点标注。因此比较固定旧位姿的残差存在**循环偏差**。即便 12° 残差较低，也不能说“视频校准了 12°”；反之，即便另一个假设残差下降，也不能自动晋升为经过校准的真实模型。这里不比较重新拟合后的最优值，也没有估计相机或尺度协方差。

该检查不提供木板刚度、摩擦、恢复系数或动力学成功的证据。20° 仍是独立几何假设；canonical 12°、相机、人工点和原参考均保持不变。
