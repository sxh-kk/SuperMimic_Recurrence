# 本机环境适配

## 适配范围

- 系统：Ubuntu 22.04，Linux x86_64。
- GPU：驱动识别为 RTX 4090，49140 MiB 显存。
- 驱动：570.211.01，驱动接口报告 CUDA 12.8。
- 独立 Python 3.12；不修改系统驱动或系统 Python。
- mjlab 固定上游提交 `8bb2bc9e187797689ec82c78c35019afd2fd0376`。

```bash
cd /home/zxc/SuperMimic
env -u PYTHONPATH -u PYTHONHOME UV_HTTP_TIMEOUT=300 UV_CONCURRENT_DOWNLOADS=4 \

env -u PYTHONPATH -u PYTHONHOME PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 uv run pytest -q \
  tests/test_g1_fk.py \
  tests/test_world_model.py::test_state_spec_identity_and_errors \
```

锁文件生成、安装结果与实际 GPU 验证结果在完成后追加。任何跳过动作数据测试的结果，不视为完整训练验证。

## 安装排错记录

- 首次预装 PyTorch 时，项目索引优先级使独立 pip 命令命中了 PyPI，未选到 `+cu126`。独立预装使用 `uv --no-config pip install` 和官方 cu126 索引；项目正常安装仍以本仓库的源配置与锁文件为准。
- 随后下载 NVIDIA 运行库时遇到默认 30 秒网络超时，将 `UV_HTTP_TIMEOUT` 设为 300，并将 `UV_CONCURRENT_DOWNLOADS` 设为 4 后重试。不修改系统代理设置或 GPU 驱动。

来源：[PyTorch 官方索引](https://download.pytorch.org/whl/cu126/torch/)、[Warp v1.18.0](https://github.com/NVIDIA/warp/releases/tag/v1.18.0)、[CUDA 驱动兼容说明](https://docs.nvidia.com/deploy/cuda-compatibility/minor-version-compatibility.html)。
