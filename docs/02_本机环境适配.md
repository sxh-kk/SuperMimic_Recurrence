cd /home/zxc/SuperMimic
env -u PYTHONPATH -u PYTHONHOME UV_HTTP_TIMEOUT=300 UV_CONCURRENT_DOWNLOADS=4 \

依赖安装已完成，并由 `uv sync --locked --group dev` 同步到锁定版本。PyTorch、Warp 的实际 CUDA 运算，以及 MuJoCo-Warp 仿真和训练更新均通过；详细结果见 [本机验证与运行](03_本机验证与运行.md)。没有下载真实动作数据，也未开始正式收敛训练。

最终再次运行 `uv sync --locked --group dev --offline`，156 个包一致性检查通过，没有额外安装或解析变更。训练测试退出后 GPU 计算进程已结束，驱动仍为 570.211.01。

## 安装排错记录

- 首次预装 PyTorch 时，项目索引优先级使独立 pip 命令命中了 PyPI，未选到 `+cu126`。独立预装使用 `uv --no-config pip install` 和官方 cu126 索引；项目正常安装仍以本仓库的源配置与锁文件为准。
- 随后下载 NVIDIA 运行库时遇到默认 30 秒网络超时，将 `UV_HTTP_TIMEOUT` 设为 300，并将 `UV_CONCURRENT_DOWNLOADS` 设为 4 后重试。不修改系统代理设置或 GPU 驱动。
- subagent 对同版 cuDNN / NCCL 分别从 PyPI 和 PyTorch 索引对应的 NVIDIA 下载服务器读取 1 MiB 测速，均为 HTTP 206。速度差异不显著，未因此中断已有大包下载或引入第三方镜像。
- 单次直连测速未见收益：Torch 直连更慢，保持原代理配置。
- 预装与项目同步曾争用同一 `.venv` 锁；已中止后启动的同步任务，待预装退出后顺序执行项目同步。后续安装应只运行上面的单条 `uv sync`，无需并发预装。
