## 当前结果不能作为完整成功教师

probe01 的最佳 `sign=+1, scale=1, velocity_gain=1` 首次触地 **2.755 s**，但准备段最小 upright 仅 **0.6656**、末根速度 **1.377 m/s**，已经明显失稳。

probe02 按现有排名选出的 `sign=+1, scale=1.5, velocity_gain=2` 首次触地 **2.745 s**、准备段最小 upright **0.6852**、末根速度 **1.058 m/s**。它的排名略高主要来自 upright 项，不能称为“存活更久”或“已站稳到预蹲结束”。2.755 与 2.745 秒的 10 毫秒差异也不应过度解释。

probe02 在 0.5 / 1.0 / 1.5 / 2.0 秒时，两脚和四轮均实际接触，机器人 upright 分别约 0.9992 / 0.9926 / 0.9950 / 0.9948，根速度约 0.071 / 0.133 / 0.039 / 0.065 m/s。它包含可用的准备段候选，但 **2.2525 秒起 upright 已低于 0.9**，2.5 秒根速度约 1.073 m/s。后续 BC 应依据实际接触、姿态、穿透与速度筛选稳定前缀，不能把整个 5.14 秒失败回合都当成合格站稳教师。

## 教师动作与策略空间的关键接口差异

probe02 控制起始时刻 0～2.00 秒（含边界）的实际 `action-reference_next_joint` 总残差最大为 **0.58844 rad**，左 / 右 ankle pitch 分别约 **0.58021 / 0.58844 rad**。按这 101 个控制样本统计，约 **63.4%** 的步至少一关节超过 ±0.25；按全部 29 维值统计约 4.13%。对于当前 pilot 的统一 ±0.35，相应比例仍为 **36.6% 的步 / 2.25% 的关节值**，也不能覆盖该教师。

原因是教师控制等于“参考＋固定偏置＋反馈修正”，两项可叠加；网络原有单一总残差限幅与这套动作空间不同。教师目标仍处于真实关节和执行器限制内，不能据总残差较大就说改了硬件限制。直接静默裁剪 BC 标签会改变教师，不再对应已验证的实际控制。

主任务已据此准备引入可选的 29 维残差限幅，并保留旧标量兼容。后续每份教师仍应对 **实际动作减对应参考** 做逐关节边界审计，再决定基座偏置、网络输出定义与 BC 标签，且保持实际环境的关节 / 力矩限制独立不变。

## 需要处理或明确的边界

- `first_ground = value or episode_end` 会把合法的 `0.0 s` 触地误当作“未触地”；应显式判断 `is None`。本轮初始无机器人触地，未影响已报告结果，但会影响带初始扰动的候选排名。
- 准备段截止物理时间写死为 2.76 秒，只适用于当前 s=1.5、视频约 4.14 秒的实验。若用于 s=2.0 或其他参考，应从显式视频截止和 metadata 倍率推导，避免把腾空段算入“准备段”。
- 反馈在任一脚有力踩板时同时修正两只脚，COM 支撑点仍取两足底 site 均值。单脚承重 / 另一脚离板时，该均值不是实际支撑中心；应区分左右加载状态，进一步考虑有力接触的支持位置和每脚修正权重。
- 速度项抑制世界根速度，未减板速度或期望运动速度。对当前站稳探针是明确的启发式；推广到滚动 / 移动 Ollie 时会同时制动合法平移，应改为任务适当的相对或误差速度。
- 姿态项趋向初始 heading 下的绝对 roll / pitch 零值，不等于跟踪每一帧预蹲期望躯干姿态。深蹲时不能只提高反馈增益，应重新核对 COM / 足底支撑与前馈姿态的兼容性。
- `no_external_forces=True` 是额外写入的固定说明，实际成功判据已依据逐子步记录检查外力。建议说明字段也从记录推导；本次独立重放确认为零，没有实际外力问题。
- 当前排名是首次触地时间与最小 upright 的加权和，不是“先保证合格准备段再排名”的门槛。为生成稳定教师，应先排除不满足准备段条件的候选，再比较误差；当前所有完整回合仍失败。

复核结论仅针对该版本原片参考反馈探针：坐标变换、实际控制和失败记录可信；它提供稳定前缀与控制方向的证据，尚不能替代完整预蹲 / 起跳 / 接板控制学习或被标为已学会 Ollie。
