# 指定 Ollie 视频：分析与实施方案

日期：2026-10-23。输入为用户提供的本机 `video/ollie.mp4`。本记录承接 [完整滑板路线](06_滑板视频完整复现技术路线.md)，将第一目标收敛到这段视频实际包含的动作。原视频及抽帧保留本机，均不提交公开仓库。

## 结论与当前完成范围

已检查视频元数据、全部帧的时间戳和解码帧哈希，并查看全片抽帧、起跳段逐帧足板细节及原分辨率关键帧。

画面为固定机位、单人全身、平地上的一次近原地 / 低速 **Ollie**：预蹲、踩尾、腾空整平、接板落地。未见明显推地、转弯、障碍物或 Kickflip / Shove-it。板面中部红白图案在起跳前后可见，不将图案误认成翻面。板尾位于画面左侧、板头位于右侧；人体解剖左右及 regular / goofy 尚未确认，标注先使用“尾侧脚 / 头侧脚”。

因此先实现该 Ollie 的完整连续执行；推地和转向不作为它的前置训练项目。HUSKY 仍提供滑板物理建模参考，但其公开推地 / 转向策略不能直接完成本视频。

**目前完成的是输入审查与方案细化。尚未运行人体三维重建、拟合板三维轨迹、完成 G1 重定向，或开始滑板物理训练。** 当前一小时 LAFAN1 训练是独立的平地基线，截止及归档结果见 [训练记录](04_LAFAN1训练记录.md)。

## 慢放假设与统一时间轴

用户估计视频“慢放了 1.5 倍”。先将 **s=1.5** 作为候选值，保留“估计、待验证”标签，不能当作已知拍摄参数。

定义 `t_video` 为文件播放时间，`t_physics = t_video / s`。s=1.5 时全片候选物理时长为 **5.171833 秒**。比较视频时可以将物理执行按 1.5 倍慢放展示，训练则使用候选物理时间及正常重力。若以视频时间表达参考，物理线速度和角速度需乘 s，加速度乘 s²；应在平滑后的物理时间轨迹上重新求导，不能只修改 FPS 标签。

保留原始 23.976 fps 帧用于板与接触标注。人体前端如需 30 fps，先按真实 PTS 重采样并保持文件播放时长；记录帧映射。随后将人体、板和事件标签一起映射到物理时间，再统一生成 50 Hz 初版参考。上采样不会增加原视频中不存在的接触证据。

5.171833 秒包含容器末帧展示区间；实际末帧观测的物理 PTS 为约 **5.144028 秒**。生成轨迹以观测 PTS 为边界，50 Hz 网格不向外推造姿态；如为视频对齐保留约 27.8 ms 的末帧展示区间，要显式标记末姿态保持，不把它当成新观测。

至少对 s=1.25 / 1.5 / 1.75 做邻域诊断，必要时扩大范围；这些是试验点，不是置信区间。联合检查地面、假设尺度、无地面接触阶段的系统质心轨迹、关节速度和接触可行性。脚在空中仍可对板施力，不能把任意板点或人体根轨迹直接当成纯自由落体拟合。单目尺度与时间存在耦合，未知人物身高 / 板尺寸时，仍需报告假设范围。

## 针对本片的优先路线

### 1. 固定相机的人板联合参考

以 [GVHMR](https://github.com/zju3dv/GVHMR) 的静态相机模式初始化 SMPL-X，保留脚部低置信度；脚踩板时不使用“脚固定在地面”的普通接触假设。视频前端放独立环境，避免改动已验证的 CUDA 12 训练环境。

使用参数化板、板头尾 / 轮轴 / 板面图案关键点，以及少量人工确认帧，拟合相机、地平面、板的连续 6D 位姿和尺度。先验证重投影与接触，暂不部署重型 RHINO 神经重建。板的对称性和遮挡需要时间连续性约束；遮挡中的补全必须保留置信度。轮速采用物理初始化或滚动假设，不声称从当前画面测得。

交付并验收人体 + 板三维回放、关键点重投影、原始 PTS 与物理时间映射。以视频中可见的板长或人物身高作假设时，明确数值来源；如有真实尺寸则重新校准。

### 2. 接触感知的 29 DoF G1 参考

先用 [GMR](https://github.com/YanjieZe/GMR) 初始化人体到 G1 的映射，再联合修正足底—板相对位置、膝踝可达范围、身体重心、板尾动作及接板姿态。标准逐帧 IK 不能保证 G1 能弹起被动板。

输出同步机器人与板参考、速度、事件标签和置信度。当前项目的机器人 CSV / NPZ 可作为人体分支，但联合任务需版本化新 schema；不能只把板列拼入旧文件就视作训练已支持。参考验收先排查穿板、脚滑、板朝向跳变、速度尖峰，以及机器人足底尺寸与板宽冲突。

### 3. Ollie 专用物理场景

借鉴 [HUSKY 的滑板 XML](https://github.com/TeleHuman/humanoid_skateboarding/blob/main/src/mjlab_husky/asset_zoo/robots/skateboard/xmls/skateboard.xml)，先在小规模场景检查自由板、被动轮、truck 和约束，再迁移到本项目 29 DoF G1。许可与版本兼容见文档 06。

- 补充适合踩尾弹板的板尾 / 板头曲面和碰撞体；原来的平盒板面不能自动代表实际 kicktail 几何。
- 滑板 freejoint 已允许整体俯仰和腾空。内部 `board_tilt_joint` 是 roll，不通过放宽它的范围来冒充弹板俯仰。
- 校准尾部触地、轮地、足板摩擦与冲击；检查接触容量，并做物理子步收敛试验。先保留 50 Hz 控制候选，若必要再提高并重新训练。
- HUSKY 的 `bad_feet_off_board` 会在双脚离板时终止，Ollie 中要按阶段处理，允许短暂离板，但须有超时、错过接板和身体碰地等失败条件。
- 腾空阶段不要求四轮触地；去除与本片无关的推地周期、目标前进速度和转向姿态目标。`board_flat` 约束内部 roll，需按实际目的审查，不能误称它直接禁止全板俯仰。
- 板无主动推进、磁吸、焊接或隐藏外力。若课程使用辅助支撑，记录辅助量，最终在完全移除辅助后验收。

### 4. SuperMimic 联合状态与阶段课程

本项目当前世界模型只有机器人状态；必须扩展板状态、参考目标、replay、解析头、重置和终止后重新采集交互数据，范围见文档 06。原一小时权重是平地基线 / 可尝试的部分初始化，不具备现成 Ollie 技能。

课程依次验证板上稳定、缓冲落地、踩尾与离地、空中整平和接板，然后在同一回合衔接。独立阶段训练可从同步的人板参考状态初始化；最终测试必须从准备段开始，不隐藏中途状态重置。奖励兼顾姿态、板轨迹、足板相对运动和接触阶段，防止仅抬腿或追踪被人为牵引的板被计作成功。

优先小批量验证真实接触和世界模型在离地 / 落地时的多步误差，再扩并行数；4096 个平地环境的内存和速度不能直接外推到滑板。目前没有该任务的本机吞吐或训练时长测量。

## 本片的验收与下一步

最终并排展示原视频、人体与板恢复、G1 与板参考、无辅助真实仿真。慢放比较版和物理时间版分别标注；1.5 倍仍以假设标识，直到校验充分。

至少记录完整连续成功率及失败时刻、板尾弹地 / 离地 / 接板 / 落地时序、板高度和俯仰轨迹、足板滑移与穿透、落地后稳定性，以及多种时间倍率 / 尺度下的可行性。全部姿态来自单目估计，三维误差只对估计参考计算，不能声称是三维真值误差。

下一批实装应先完成 **独立视频前端部署、带时间映射的人体与板参考、可检查的三维回放**；参考尚不可靠时不启动大规模 Ollie 训练。本次未安装新模型、下载权重或更改正在运行的训练。
