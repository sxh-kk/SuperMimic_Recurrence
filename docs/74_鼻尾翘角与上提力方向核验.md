# 鼻尾翘角与上提力方向核验

2026-10-25。**当前12°翘面确有一个与Ollie相关的力学限制：在后轮支撑、纯俯仰至尾部刚触地的姿态下，μ=0.9的nose顶面接触不能对板产生向上合力。**20°固定接点候选在同类姿态下允许正的摩擦锥外包上界，但需要更大的板身抬头角；这不等于已找到实际接触、机器人控制或正确的视频板参数。

该检查借鉴[开源Ollie力学源码中的20°示例和尾触地几何](https://github.com/mechmotum/ollie-optimization/blob/dd60b1984a236dd682c9677345c55a168957651f/thesis-files/MultiPhaseOllieOptimization.py#L130-L140)。控制算法保持SuperMimic，canonical板和训练模型均未被替换。

## 两个固定几何

入口`scripts/local/audit_ollie_kick_geometry.py`。

- 基线直接编译原板：鼻尾约12°，原中心位置、尺寸、轮半径/轴位、质量不变。
- 候选20°：保持每段原有**内端下缘接点**，旋转同样长度/宽/厚的鼻尾盒并相应移动盒中心；没有把整个鼻尾原地旋转而撕开接缝。组件质量逐值保持，新的组合惯量由新几何重新计算并报告，未冻结旧惯量冒充相同物体。
- 两者都只建立独立board-only几何。假定后轮支撑地面、板没有roll/yaw，求真实tail盒最低点首次为0的纯pitch角；轮的真实圆柱几何也参与核对。

## 力方向的含义

设nose顶面倾角为α，脚位于它上方。作用于板的法向力向下，最大向上摩擦分量受μ限制。以法向力N归一化，圆形摩擦锥外包给出：

```text
F_board,z / N ≤ −cos(α) + μ sin(α)
```

12°基线在首次触尾姿态的上界为负，因此**任何该顶面内的接触**都不能靠这组法向/摩擦方向向上带板；简单增大同方向的力只会更向下。它不排除之后更大板pitch、有限鼻边/端面或其他接触模式。20°的正上界仅表示外包摩擦锥在方向上不再排除上提；原生pyramidal锥、具体接触切向基、鞋碰撞几何、全身可达性和持续法向挤压仍可能使实际接触失败。

鼻面更陡同时使尾触地角从26.84°增加到31.62°，不能认为“加翘角就一定更容易起跳”。质量/惯量、视频重定向、腿部动作与撞击时序都需要重新检查。当前两份几何均没有elastic deck，尾地耗散也没有被重新标定。
