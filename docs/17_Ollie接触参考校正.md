# Ollie 接触感知运动学参考

## 范围与实现

本阶段把 GMR 的机器人初始化与估计的滑板 6D 轨迹合成 92 维联合参考。入口为 `scripts/video/build_ollie_reference.py`，算法组件为 `src/supermimic/ollie/contact_ik.py`，沿用 `JointReference` 的版本化 NPZ 契约。

这是在真实 G1 模型几何上进行的**运动学校正**。计算中调用 MuJoCo FK、Jacobian 和碰撞检测；不前进物理时间、不施加控制力、不对板施加隐藏驱动力，也不把参考位姿回放当作 Ollie 物理成功。关节和根速度有运动学上限，仍未求解力矩、接触力、摩擦锥、平衡或可达的完整弹板过程。

## 输入与共同坐标

机器人输入为 `logs/ollie_gmr/common_world/g1_robot_50hz.npz`：258 帧，50 Hz，物理时间 0～5.14 s，展示时间为物理时间的 1.5 倍。1.5 是待校验的用户慢放倍率假设。

本轮最终采用板拟合第三版 `logs/ollie/board_reference_v3/board_reference_50hz.npz`，包含：

- `board_qpos (N,7)`：共同 Z-up 世界坐标下 xyz 米、根四元数 wxyz。
- `time_physics (N,)` 与 `time_video (N,)`：须与机器人完全对齐。
- `board_pose_confidence (N,)`：0～1 工程可信度，不是标定后的概率。
- `phase (N,)`，可选 `phase_names`；标准名称依次为 prepare、crouch、pop、flight、landing、recovery。
- `foot_board_prior (N,2)`：SMPL 解剖左/右脚先验，-1 未知、0 无接触、1 接触。不能由 phase 直接推导整段双脚接触。

共同坐标来自 `data/ollie/common_world.json` 的单一相机到世界变换，其板尺度和地面对齐仍是单目工程估计。GMR 使用的根/腿缩放为 0.866，上肢比例不同；板保持实际物理模型的原尺寸 **0.8013×0.21 m**，不悄悄缩成 0.694 m 长。适配组件通过明确记录的机器人根平移校准处理尺度与全局平移错位。

在明确接触的样本上，根平移校准将活跃足底中心相对板的平均位置移到板中央附近，并对齐平均支持高度。在未知/腾空间隙中线性插值这些校正，再做轻度时间平滑。该过程会改变原始 GMR 全局平移，目的是去除不一致的根漂移；它不是新的相机测量，也不是独立验证过的人体世界轨迹。

## 足底、接触与时序约束

使用实际物理场景内的 `left_foot`、`right_foot` sites，其足部局部位置为 `[0.04,0,-0.037]`；它们不是脚踝关节位置。每只脚另读取七个真实足部碰撞胶囊，沿当前板法向计算胶囊的最低表面支持点，修正 site 到足底表面的高度差。

只在明确接触先验等于 1 且板位姿可信度超过阈值的样本加软约束。可以用 `--stance-video-window START END` 指定人工保守站稳区间；一旦指定，它们会替换上游的正接触工程先验，避免不知情地把约束延伸到整段。区间写入 metadata，并且不能与标注为 flight 的帧重叠。未知标签保持未知，腾空阶段不约束足底与板固定。

每个连续接触段分别估计脚在板局部的 anchor 和 yaw。anchor 中心限制在板中段，允许脚的前后缘合理悬出板宽。通过有界最小二乘在浮动根 6 维与 29 个驱动关节上优化足底位置和朝向，同时保留对 GMR 姿态的软跟踪。足底垂向 Jacobian 取真实胶囊支持点，平面位置 Jacobian 取足底 site。角度/速度上限在求解内处理，避免优化器反复请求已经被截断的踝运动。

所有阶段均对真实碰撞发现的足板穿透加入单向分离软约束；另在板附近使用保守的上表面平面约束，避免参考脚从薄板上方穿到下方。非线性几何回溯拒绝新引入穿透的迭代步，防止最后一次迭代停在“穿入/推出”的半周期。未知/腾空段仍可分离或滑动，不绑定足板相对位姿。该 anchor 只用于参考优化，不在 MuJoCo 场景中创建 weld/equality。

先对关节位置做时间平滑，再限制相邻帧关节变化，默认最大 12 rad/s、根线速度 3 m/s、根角速度 8 rad/s。关节位置同时满足真实模型限位。最后从校正后的姿态在物理时间上重算速度，而不是把原展示时间速度直接沿用。速度限制和姿态目标冲突时保留残差并报告，不能宣称约束都已满足。

## 输出和 QA

主输出为 `JointReference`：机器人 71 维 + 板 21 维 = 92 维，关节顺序和 wxyz 与状态组件一致。板的四个轮角/轮速设置为 0 并标记 `wheel_motion_observed=False`，表示未观测初始化；学习跟踪目标应屏蔽这八个轮参考量，真实物理轮状态仍可用于世界模型训练。

同名 JSON 保存来源 hash、缩放、人工时间窗、校准方式、IK 参数和 QA。另存 `_diagnostics.npz`，包含每帧根平移校准、接触约束 mask、足底到板面间隙、接触段 anchor 平面误差、真实 foot-board 碰撞穿透和校正前后 qpos。未知段的 anchor 误差为 NaN，表示未施加该约束；联合参考本体仍要求全部状态有限。

当前几何 QA 阈值为：接触段最大支持高度误差 2.5 cm、最大平面 anchor 误差 4 cm、全段足板碰撞最大穿透 1.5 cm、关节限位误差 1e-6 rad。阈值通过只说明这组运动学几何检查通过。身体碰板、自碰、脚完全离开板面范围、板本身穿地和受力可行性不由这组阈值认证。

## 已执行验证

初版已完成 12 帧合成站板 CPU 验证，以及中间解除四帧接触约束的几何分离检查。完整 builder → 原子保存 → `JointReference.load()` 读回得到 12×92 状态，结构验证通过。合成检查不是 Ollie 视频结果。

最终版已实际处理真实视频恢复的人体和板第三版轨迹，生成 `data/ollie/joint_reference_50hz.npz`，同名 `.json` 保存报告，`joint_reference_50hz_diagnostics.npz` 保存逐帧诊断。运行命令为：

```bash
CUDA_VISIBLE_DEVICES='' OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
.venv/bin/python scripts/video/build_ollie_reference.py \
  --robot logs/ollie_gmr/common_world/g1_robot_50hz.npz \
  --board logs/ollie/board_reference_v3/board_reference_50hz.npz \
  --out data/ollie/joint_reference_50hz.npz \
  --stance-video-window 0 2 --stance-video-window 6 7.716042 \
  --min-confidence 0.3 --ik-iterations 24
```

准备/恢复板姿态的可信度是 0.35，来自近地面姿态和时间先验而非可靠的三维板面观测。本次显式采用阈值 0.3 以使用这些工程先验，没有提高上游置信度。0～2 s 和 6～7.716042 s 均为**视频展示时间**；每脚最终施加 125 个样本的接触约束。中间起跳、腾空、接板和初次落地不被这些站稳窗硬绑。

真实 258 帧结果：

- 状态 258×92，全部有限，单位根四元数、关节顺序和两条时间轴通过 `JointReference.load()` 验证。
- 接触段最大足底支持间隙 **0.820 mm**，平均绝对间隙约 0.799 mm；最大平面 anchor 误差 **0.149 mm**。
- 全段真实足板碰撞最大穿透 **1.394 mm**；关节限位误差为 0。
- 最大相邻帧关节速度 **12 rad/s**，最大根线速度约 2.697 m/s，最大根角速度约 3.363 rad/s，均在本次配置边界内。
- 根平移校准各轴最大绝对量约 x=0.128、y=0.420、z=0.110 m。这一改动不可忽略，必须随参考保存，不能把最终根轨迹称作未经调整的视频测量。
- Ruff 和 Python 语法检查通过。尚未进行动力学控制验收、碰撞全项验收或物理视频成功判定。

板第三版只有中央腾空的九个原始帧具有较强的图案透视证据，其空中重投影误差较小；地面段板端仍有约 17～20 px 残差，轮/地约束和尺度假设仍在发挥较大作用。因此，这份几何 QA 通过的参考适合后续控制研究，不能反推原视频三维动作已经准确恢复。
