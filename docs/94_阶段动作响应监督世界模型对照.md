# 阶段动作响应监督世界模型对照

2026-10-29，实验前固定。本次只检验SuperMimic人板世界模型能否从93的默认μ=.6真实数据学到板VZ动作响应；不训练actor、不开放板BPTT、不修改原ContactWorldModel/JointStateSpec积分或codec，不把任何失败分支晋升为教师。

## 问题与固定对照

73旧批次的paired loss并非在数值上被state loss掩盖：控制臂paired/state比值首步1.087、中位3.751、末步4.712。旧H1板VZ尺度1e−4 m/s过小，新93训练真实差RMS已达.0126233 m/s；直接复用会把该坐标放大约126倍。73未记录分项梯度范数，不能仅凭标量比值推断梯度贡献。

新入口`../scripts/local/fit_ollie_phase_response_wm.py`仅读取93冻结`paired_responses.npz`，SHA256 `7e638c771d017ce6b225734ef08f75e24fc31c9e5ba2dba6fed3a1e8ff6d0a34`。372训练/186留出分支，180/90真实关节正负对；不混72的μ=.9数据。45条原10 mm质量门槛失败分支带失败标签保留，不能把数据有限当作安全教师。

- `state_only = L_state`：原H8自由递推归一化状态误差，轮8项权重.05。
- `state_plus_response = L_state + 1.0 L_vz`：增加板根世界VZ正负动作差分监督，辅助头权重均0；head、状态维数、动力学网络和积分形式均不改。

真实目标`Δv(g,h)=v_true_positive(h)−v_true_negative(h)`先以float64相减；预测从相同真实热初态，分别使用实际正/负H8目标自由展开，不teacher-force。h取1与8；每个g为六个固定采样角色之一。训练尺度`s(g,h)=max(RMS_train Δv(g,h), [.001,.005] m/s)`，只由训练对冻结。`L_vz`为六角色×两个时域共12组归一化响应平方误差均值；不混合位置/角度单位、不除名义脉冲幅度、不把有限差当解析Jacobian。

六角色在每个pair batch中各10对，共60对；普通state batch64。训练/留出依93整热锚点划分，不按兄弟分支拆分。角色是采样位置，不代替实际接触标签；tail邻域包括触地前热状态，air角色H8未来可能落地，指标另报实际覆盖和角色边界。

seed94、hidden(512,512,512)、Adam lr2e−4、梯度范数上限1、最多500对更新。两臂同初值、同state/pair批次，预先保存全部500批次及哈希；inspect时保存初始权重与输入/尺度/分组manifest。正式总预算300秒，270秒后不再接收新成对更新，为保存/评估留余量。先计算两臂全部梯度并核有限，再事务提交两次Adam；第二臂异常时两臂权重和Adam状态全部回滚，计数只在两臂完成后增加。中断信号在成对更新边界处理，禁止一臂多训练一次。

固定训练batch在0/100/250/500次更新处测state与response梯度范数和夹角，耗时计预算；不据此改权重。留出仅用于最终诊断，不用于尺度、批次、权重、seed、停止或checkpoint选择。未完成500次则保存实际更新数和停止原因；不追加训练。

## 指标与预注册门槛

最终训练/留出均报告H1/H8板XYZ位置、VXYZ速度每轴和向量RMSE。正负板VZ响应单列真实SI单位RMSE、零动作响应基准RMSE、能量投影gain及符号率（仅|native Δv|>1e−6 m/s，样本数单报），分别报告总体、六角色及tail/air/landing聚合。

局部诊断门槛：留出总体及tail/air/landing在H1/H8均满足响应RMSE≤零响应基准的.8、gain∈[.5,1.5]、符号率≥75%；H8板速度向量误差不能劣于state-only和初始速度保持基准，H1/H8板位置误差不能比state-only恶化超过10%。位置改善不掩盖速度错误，没有以结构closure作为准确性证据。

即使上述局部门槛通过，也仍`board_bptt_allowed=false`、actor更新0：93来自一个失败回合的相邻重叠热状态，没有空中双足catch和稳定落地教师；通过不等于独立技巧泛化或完整Ollie完成。独立CPU读回只允许评估，不再训练；其耗时另报。

以上为实验前固定约定，下文为唯一正式结果。没有再次拟合、改loss权重或根据留出挑checkpoint。

## 梯度诊断与边界

固定训练batch的state/response梯度范数：初始化`1.29227/.02772`，第100对更新`1.10059/.79756`，250对`2.73188/.47108`，500对`4.77759/.96604`；夹角余弦分别`−.00216/−.08391/.35074/.06067`。初始化response loss为1.31583却只有较小参数梯度，说明loss标量大小不等于实际梯度贡献。记录仅用于解释，没有据此调权。

额外仅从已保存初始/最终权重作CPU分项梯度读回，未训练，100/250中间权重未保存因此不补造分项值。最终固定batch的H1/H8响应loss为`.39656/.49023`，各自乘.5之前的梯度范数`1.12598/1.96022`，H1与H8梯度余弦`−.31200`；state对H1/H8余弦分别`−.04089/+.08339`。可确认短/长响应目标存在相互抵消，**不能据此声称H8在该batch上直接反着state梯度**。同时，末50次训练state loss均值由state-only`.05562`升至实验臂`.08905`，结合留出绝对rollout恶化，说明该附加监督付出了状态拟合代价。分项CPU结果在`loss_component_gradient_readback.json`，探索分析没有触发新训练或权重选择。

采后另对已有预测作探索性H2～H7读回，**不是预注册门槛或新训练选择**：实验臂总体H2响应gain已降至.02568、符号率53.33%，H3 gain−.03032；H6～H8绝对速度误差快速增大。这提示问题从递推第二步就出现，不能认为H1局部方向学会便可开放H8策略BPTT。完整数据在`exploratory_horizon_readback.json`。

92维输入不包含MuJoCo完整热求解器状态；数据分支虽继承真实warmstart，网络只学习当前可见状态的条件近似。采样角色既没有作为新输入，也没有用真实未来接触替代模型动态。后续若改多步监督、状态表示或采样，须单独登记新的比较，不能把本轮失败改写为成功。
