# Ollie 联合动力学与闭环学习原型

2026-10-23。这里记录新增人板学习分支的实际检查与训练。它不替换原71维平地任务，也不把原一小时权重当作已支持滑板。

## 已实现的运行路径

- `src/supermimic/ollie/gpu_env.py`：原生 G1 + 被动板模型进入 MuJoCo-Warp；92维按地址读写，29个绝对关节PD目标按名称映射，50Hz控制、8×0.0025s物理推进。没有板电机，没有每步重写qpos，没有自动重置。
- `learning.py`：94维归一化联合状态特征、29维控制输入、90维状态更新的世界模型；三个512单元隐藏层为工程原型，不是原论文网络参数的直接复现。固定场景暂不加入域随机化xi。
- 同文件提供目标编码器 + 有界PD残差策略和可微跟踪目标；策略使用完整仿真状态，不是原论文的930/680观测设置。参考未观测到的四轮角度 / 轮速不进入跟踪目标，实际轮状态仍进入世界模型。**目前策略类不是已经训练完成的Ollie控制器。**
- `scripts/local/train_ollie_wm.py`：采集真实GPU物理转移、按独立环境回合划分训练 / 留出集、8步自回归模型学习、保存数据 / 权重 / 指标。

## GPU 场景实测

8个并行人板场景、10个控制步、92维输出有限，CUDA graph实测通过。Warp1.18对包裹的Torch null stream捕获报unknown stream，已改为独立可捕获Warp stream，并在Torch/Warp边界显式同步保证读写顺序；目前优先正确性，未优化这部分同步开销。

MuJoCo-Warp提示capsule/cylinder对不支持MULTICCD多接触，最多产生1个接触。这影响脚碰轮等配对的数值细节；不把GPU与CPU的接触回放宣称为逐位一致。轮地和足板行为仍需任务级验证；不能仅凭状态有限就认定跳板正确。

## 首次联合世界模型 pilot

命令：

```bash
env -u PYTHONPATH -u PYTHONHOME uv run --locked python scripts/local/train_ollie_wm.py \
  --out-dir logs/ollie_wm_pilot_01 --num-envs 64 \
  --collect-steps 48 --updates 500
```

- 64个环境各48步，共 **3072条真实物理转移**。控制为小扰动站板 / 蹲起尝试，尚无经验证的目标踩尾、完整腾空与落地覆盖；失败或偶然离地不当作成功示范。
- 训练采用56个完整环境回合，留出8个完整回合。没有将同一回合的重叠窗口随机拆到训练 / 留出两侧。
- 采集连初始化约2.25秒；采集加500次模型更新合计约37.08秒。损失和梯度有限，模型与物理数据保留本机。
- 固定留出窗口的平均自回归归一化损失由 **0.39182降至0.02967**；1步误差0.001786→0.000715，8步误差1.4918→0.10153，板部分8步误差6.4495→0.33887。
- 这些是按工程尺度归一化的状态预测指标，不是米制轨迹误差、成功率或视频动作复现指标，不能外推至尚无覆盖的起跳 / 接板。
- 本机文件为 `logs/ollie_wm_pilot_01/model.pt`、`physical_transitions.pt`、`result.json`。检查点格式为 `supermimic.ollie.wm_pilot.v1`，与原平地权重不兼容。

在该真实物理数据上另做冻结世界模型的4步BPTT集成检查，批量8。首次检查暴露四元数函数不接受隐式批量广播，已将当前状态显式扩展到三个未来目标的批量形状；修复后的实际检查损失0.06366793、策略梯度范数0.00540936，均有限且梯度非零，输出为 `bptt_check.json`。这只证明梯度路径接通，未将该检查称为策略训练或Ollie成功。

## 仍需完成

### 已接通的交替训练入口

`scripts/local/train_ollie.py` 已实现真实物理采集 → 独立回合留出世界模型更新 → 冻结模型的策略BPTT → 首帧连续真实GPU筛选，并保存 `supermimic.ollie.actor.v1` 策略检查点。训练可以从参考不同阶段初始化以增加覆盖，**完整筛选回合只初始化一次，初速为零，无中途重置或板外力**。仅29个机器人PD目标进入物理场景，范围与原关节限位一致。

在16环境/16步、2轮交替、每轮5次模型更新和2次4步BPTT的真实集成检查中，共采集512条转移；策略梯度范数0.00246和0.00491，全部有限，脚本约8.69秒结束。初始参考PD和两轮策略的完整连续筛选均摔倒；因此这次仅证明训练循环与检查点实际可运行。产物为 `logs/ollie_actor_smoke_01`，未称为Ollie成功。

工程跟踪损失、短时滚动模型和全状态观测仍需进一步校验。筛选分数用于排序，不代替物理接触验收；原生CPU的独立接触逐子步评测见后续闭环记录。

接入通过几何QA的人板参考后，采集覆盖踩尾、自由飞行、离板与落地的真实状态转移；按回合留出检查各阶段的多步误差，再进行策略BPTT和真实仿真闭环迭代。联合策略最终须从站板准备开始连续执行，按真实尾地接触、轮离地、接板落地和机器人稳定性验收。

CPU轨迹参数搜索仅作为物理可行性基准和数据来源，不能与SuperMimic学习策略混称。参考是运动学估计，不能逐帧强写机器人 / 板姿态来制造“物理完成”。
