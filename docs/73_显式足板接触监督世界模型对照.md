# 73｜显式足板接触监督世界模型对照

本批实现的是 **SuperMimic 当前 Ollie 世界模型的监督消融**，继续使用 `JointWorldModel → DynamicsMLP → state delta → integrate`；不训练策略，不执行 BPTT actor 更新，不用预测接触力驱动物理。它不等于已完成论文的全部复现，也不改变严格完整 Ollie 仍 FAILED 的结论。

## 先固定比较，再执行

两臂参数首次正式运行前固定为：seed73；每臂最多500次更新；batch64；Adam lr=`2e-4`；hidden=`(512,512,512)`；梯度范数上限1；H8；轮状态误差权重 `.05`；成对响应项权重1；辅助项仅实验臂权重 `.1`。总墙钟预算240秒，拟合在220秒停止接新更新，为诊断和安全保存预留20秒；每次完整更新/保存不能中途抢断，真实总耗时必须写出，不把未完成500次写成完成。

- `control`：`L_state + L_paired`。
- `auxiliary`：`L_state + L_paired + .1 L_aux`。

两个模型由同一个新初始化模型深复制，包含完全相同的主网络、辅助头初值；未读入旧 μ=.6 WM、BC 或 actor 权重。使用同一个预先固定的 CPU generator 为每次迭代生成普通窗口和配对索引，再同时交给两臂；记录共同初始权重哈希、每臂实际已完成更新及批次索引哈希。被中断时不得隐瞒两臂更新数可能不同。

## 状态、成对响应和辅助头

新 `ContactWorldModel` 继承现有 `JointWorldModel`，复用 `dynamics.mlp.net` 的全部隐藏层和原90维delta末层。另加 `Linear(512,8×22)` 辅助头；每步从相同隐藏特征预测8个post-forward物理样本。原 `step(state92,action29)` 仍使用原状态路径；辅助输出没有拼进state92、没有作为物理残差或仿真力。

状态损失保持H8自由递推的原归一化误差，轮位置/速度最后8项权重 `.05`。配对损失沿42方法：从同一初态分别执行保存的正/负实际H8动作，不在中间teacher-force；取H1/H8的机器人和板世界位置、旋转log、线速度、世界角速度共24个SI响应。真实target先用float64相减，没有把有限幅差除以名义扰动叫无穷小Jacobian。

固定成对尺度沿42：robot xyz `.001 m`、旋转`.005 rad`、速度`.05 m/s`、角速度`.1 rad/s`；board xyz`.001 m`、旋转`.005 rad`、速度`.01 m/s`、角速度`.05 rad/s`；仅board VZ在H1用`.0001 m/s`，H8用`.01 m/s`。没有从留出数据拟合这些尺度。

22项辅助量为：

- 两脚真实上表面向上支持、左前脚→nose净世界Fz、tail-ground法向力，共4项，变换 `asinh(force_N/100)`。
- center/tail/nose/两轴/四轮完整9个geom最低点，除以 `.05 m`。
- 全系统COM世界VZ，除以 `1 m/s`。
- tail-ground、nose-ground、左右foot-board、左右foot-ground、any-robot-ground、any-board-ground，共8个真实0/1 flags。

`L_aux` 是以上22量×8物理子步的均方误差，在每个H8预测状态输入对应动作时计算，未teacher-force到真实中间状态。原始post-forward force是新状态重新求解后的力，**不是刚结束积分所施冲量**；head拟合成功也不等于已实现真实力。

## 输出与边界

正式拟合入口默认只inspect，必须显式 `--execute-approved-fit` 才会优化。保存 `initial.pt/control.pt/auxiliary.pt`，schema=`supermimic.ollie.contact_aux_wm.v1`，含原始模型/辅助头、optimizer、结构、材料与数据manifest、updates、停止原因和批次哈希；均为基础类型与Tensor，可用 `torch.load(...,weights_only=True)`。这是新WM schema，不能当旧actor/BC checkpoint加载，也未自动接入原训练入口。

结果分别报告训练与留出H1/H8板XYZ、VXYZ各轴/向量RMSE；24项正负实际响应的误差、零动作效应基准、能量投影gain和符号率，符号只计`|native_response|>1e-6 SI`。gain为`Σ(pred×native)/Σ(native²)`，不是逐个除以微小响应。输出每组事件样本覆盖，辅助MSE单列，不能以更小状态误差替代动作响应校准。

**72本批实际覆盖没有tail-ground、前脚向上带nose力、whole-board>5mm腾空事件。**因此即便支撑/卸载留出指标改善，也不能认证pop/drag/catch梯度。所有输出保持 `board_bptt_allowed=false`、`ollie_gradient_certified=false`；不自动改变验收阈值或启动actor。

240秒预算包含读数据、初始化、两臂优化和已执行诊断；每次更新间及诊断前检查deadline。若耗尽则保存实际已有模型并明确跳过未完成诊断；异常/KeyboardInterrupt用finally原子保存模型和实际更新数。不能因部分检查跳过称其全部过关。

### 保存与实际结论

**这次实验没有解决留出的板速度/动作响应问题，不支持开启board BPTT。**训练和留出数据的真实tail≥5N、前脚→nose向上力≥1N事件样本均为0，且没有真腾空覆盖；因此任何低辅助loss都不能认证pop、drag或catch。维持`board_bptt_allowed=false`、`ollie_success_certified=false`，当前完整物理Ollie仍FAILED。
