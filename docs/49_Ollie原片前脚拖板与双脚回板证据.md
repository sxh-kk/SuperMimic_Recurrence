# Ollie 原片前脚拖板与双脚回板证据

原分辨率逐帧证据支持：前/左脚在起跳至空中与板鼻存在持续接触的候选关系，早期更像鞋侧或鞋尖沿板鼻拖动；后/右脚离尾后在video约4.92..4.96s已回到板上，双脚到5.3387s落地时明显覆盖板面。当前参考把机器人与板完全分离直到video约5.97s，与这些图像不一致。

这些是二维可见关系和显式工程接触候选，不能据此声称已经恢复了三维接触力。足与板贴合或遮挡不能测出压力；也不能为了补上动力学缺失力而把整段强行焊接。

## 只读输入与检查方法

原片 `video/ollie.mp4`：1920×1080、186帧、24000/1001fps。SHA256 `a7288f4abbccee27f756bb620c71826ba47b7e13f1786ac901eaa9a40002ddb2`。本轮抽取106..130帧，在原像素密度下裁剪 `(x=590,y=350,w=760,h=650)`，未修改或重编码原始视频。

使用容器原始PTS，不能把7.757750s容器末端当作末帧PTS。physics=video/1.5仍为假设时间映射。

比较两个冻结参考：

- 踩尾/upright v4：`data/ollie/tail_contact_upright_v4/joint_reference_50hz.npz`，SHA256 `38243f1cc2c37ce1461817e83ced08410d90a332692a8c1d44dbb89dd54994e7`。
- 46最终global COM候选v3：`data/ollie/ballistic_tail_upright_candidate_v3/joint_reference_50hz.npz`，SHA256 `1611f169de8e5df7442aadccabd309f2ecbc33b9acd1f530ca9f774c68b997d8`。该候选明确仅满足部分整体必要条件，组件动力学仍失败，不能视为物理成功参考。

在原PTS对应时刻，用MuJoCo广义位姿插值取得机器人和板，逐个查询7个真实足胶囊到中心/尾/鼻有限碰撞盒的最短有符号距离；没有把参考 `mj_forward` 力当成实测力。

投影沿用固定common_world相机，K焦距2202.9072px、主点(960,540)，保留单目尺度、深度和少量相机抖动的不确定性。红色线段是“真实3D最近胶囊-盒子点对的投影”，不是最小二维轮廓距离，也不是与原片鞋点一一匹配的重投影残差。

## 前/左脚：板鼻拖动候选

前脚是画面右侧的鞋。逐帧检查106..130帧后，未发现它像现参考那样与板鼻产生数十像素的清楚空隙。

- 106帧，video4.421083/phys2.947389s：前脚仍靠近板前部上面，鞋边与板边邻接。
- 108..113帧，video4.504500..4.712625s：板明显抬头；鞋侧/尖沿翘鼻相邻。鞋法向没有明显与板面法向对齐，不能用“平脚掌焊到nose平面”的模型代替。
- 114..117帧，video4.754750..4.879875s：板已腾空，前鞋仍遮住/贴着nose边缘。原像素近邻鞋边与可见板边的手工见证点间隔约2..5px，估读不确定度±5px；支持接触候选，不足以确定三维压力点。
- 118..130帧，video4.921583..5.422083s：前鞋压住或遮挡前部griptape区域，板逐渐放平并落地。脚下板面被遮住，不能把人为同一点标注当成“观测到零间隙”，因此这些帧不填写虚假的精确像素接触距离。

目前没有清楚图像证据支持在4.42..5.34s中间插入一段前脚明确完全离板。连续前脚接触可以作为需检验的工程先验；接触是否瞬间卸载、鞋与板的深度距离及实际力仍未知。

## 后/右脚：释放与空中回板

- 106帧4.421083s仍接近尾部；108帧4.504500s已经明显离尾，释放时刻落在两者之间。
- 108..116帧4.504500..4.838167s，后鞋与板面可见分离。手工选取的近邻可见边缘点对间隔约21..36px，足以区别于前脚贴边；它们是可检查的近邻见证值，不是自动求出的全轮廓最小距离。
- 117帧4.879875s，后鞋与板边间隙已缩小到约15px，边界判断较弱。
- 118帧4.921583/phys3.281055s，后鞋接近板面，约4px见证点间隔，接触尚不确定。
- 119帧4.963292/phys3.308861s起，后鞋覆盖板后部griptape，120帧5.005s及随后帧持续可见同类贴板关系。这支持把回板候选窗口放在phys约3.28..3.31s，而非3.98s。
- 128帧5.338667/phys3.559111s，两鞋明确覆盖板上表面，四轮明显接地；130帧5.422083s仍如此。轮子接地时刻可再细化，不能仅凭一张图测定冲击力。

## 下一最小候选

可新建运动学分支而不修改现有参考：保护v4准备0..2.76s；前脚从center向nose滑动，允许真实有限nose的上面或边缘与鞋尖/侧接触，不强行对齐脚Z轴。2.76..2.80s若为严格保留前缀速度而无法改首邻节点，应标过渡未知，不伪改速度。

保留后脚起跳后的明确释放段，phys约3.28..3.31s设置回板过渡候选，最晚约3.56s双脚回板。接触点位置、滑动路径和摩擦力均为待验证工程先验；不能把源片被鞋遮住的区域包装成已恢复的3D接触点。

46主air联合COM目标可作为硬约束，同时改变根/腿/必要腰重新重定向，板与手臂保留。每次关节修改必须重新核对全系统COM、真实有限盒接触见证、脚不穿板、全身碰撞≤2mm、真关节限位及12rad/s。如果这些目标同时不可达，应明确FAILED候选，并允许重新拟合板轨迹/尺度/PnP；9个单目PnP节点不能因原先固定过就被当成物理真值。
