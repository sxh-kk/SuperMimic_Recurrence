# Ollie 尾撞释放与上提作用机制验证

本次固定机械夹具路径未形成有效的净向上提板冲量，也未使整块滑板离地。最大所有接触穿透为 **3.011 mm**，因此没有因超过 10 mm 而拒绝这条测量，但结果仍为失败。它提供的是组件接触机制证据，不是 G1 执行、准备教师或 Ollie 成功。

## 要回答的具体问题

[61 号模型审计](61_Ollie滑板与足板接触模型审计.md)及 `scripts/local/audit_ollie_board_impact.py` 已检查四个固定被动尾撞工况。以人工初始角速度 −3 rad/s 的工况为例，尾部数值接触点入射速度约 −1.302 m/s，力释放时约 +0.0013 m/s，表现出很弱的法向回弹。该速度比不是木板材料恢复系数，也不能单独推出“此模型一定不能 Ollie”。本次不重复四个尾撞工况。

Ollie 的板动量可以同时受到地面尾撞、前脚侧面/鞋尖接触以及后脚卸载时序的影响。本次只检验其中一个有限鼻端接触路径；**没有把尾撞与前脚上提串成一个完整技巧，也没有测试真实机器人能否实现该路径**。

## 事先固定的设备与动作

入口为 `scripts/local/check_ollie_tail_release.py`，只接受输出目录，不暴露优化参数。配置在观察任何结果前发给 root 并确认，没有参数网格或根据结果修改路径。

- 滑板从原始四轮水平接地、速度为零的状态开始。原板质量 2.18 kg，几何、惯量、四个被动轮、重力、接触参数均保持原值；脚板合成摩擦系数 0.6，`solref=[0.02,1]`；尾地原值为摩擦 0.9、`solref=[0.008,1]`。
- 从原 G1 左脚复制全部七个胶囊的形状、局部位姿、材料、接触优先级，以及脚体 0.608 kg 的质量与惯量。脚绕世界 Z 轴转 90°，横放在板头外侧；包络与鼻端外包络初始 X 间隙 1 mm、Z 中心与有限端面中心对齐，无初始穿透。
- 脚装在**独立机械设备**的三个平移关节上，方向固定。每轴位置伺服刚度 **10000 N/m**、阻尼 **200 N·s/m**、力限幅 **250 N**。固定朝向导轨和这些驱动能力均不代表 G1 能力；使用有真实速度的动态滑动关节，避免仅移动 mocap 位姿造成接触速度含义不明。
- 目标位移相对夹具起点，以各段五次平滑曲线连接：0–40 ms 向 −X 压入至 25 mm；40–240 ms 继续到 −X 120 mm、同时上提 Z 200 mm；240–320 ms 撤到 +X 80 mm，Z 保持 200 mm；保持至 400 ms。物理步长固定 2.5 ms。

只有夹具的三个伺服能输入能量。滑板没有电机、焊接、运动学锁定或直接外力；整条运行仅一次初始状态赋值，之后不写任何物体的 `qpos/qvel`。夹具受世界导轨约束，但滑板只受到重力和自然接触力。

对于初始 12° 鼻端端面，摩擦锥允许的板竖直力上界为约 `(-sin12° + 0.6 cos12°) Fn = 0.379 Fn`。这是几何受力上界，要求适当的滑动方向及持续接触，不能直接当成已实现的力。实际有效接触的原生锥上界范围为 0.3790–0.3791 倍法向力，说明接触面并非在几何上完全排斥向上力。

## 实际结果

完整记录位于 `logs/ollie_tail_release_01/`。运行本身约 **1.93 s**，保存 160 个实际控制间隔与 161 个状态边界，未改路径重试。

- 脚与板头的有效接触出现在 **22.5–50.0 ms**，共 11 个物理间隔、22 个原生接触点记录；均为 `left_foot7_collision` 对 `board_nose`。50 ms 后不再有有效脚板接触。
- 法向力给板的竖直冲量为 **−0.300632 N·s**；切向摩擦给板的竖直冲量为 **+0.221403 N·s**；合计仍为 **−0.079230 N·s**。一个 2.5 ms 间隔出现 +0.54265 N 的净向上分力，正值部分冲量仅 0.0013566 N·s，发生在设定上提段开始之前，不能称有效提板。
- 最大整板质心上升速度仅 **0.001097 m/s**。按全部板盒体、轮圆柱支持函数计算，整板最低点最大值约为 0；超过 5 mm 的连续离地时间为 **0 ms**，尾部没有有效地面接触。末时四轮均有地面接触。
- 板的质心 X 位移为 **−0.229223 m**、末 X 速度约 **−0.62046 m/s**。压紧首先把无约束滑板向后推走；脚在上提段刚开始时即失去接触，不能沿既定世界路径继续带板。
- 最大所有接触穿透 **3.011 mm**，来自脚胶囊与板头，低于本次 10 mm 上限。该上限只限制异常穿透，不把失败判为成功。

该路径的失败定位是“未维持有效上提接触”，没有证据把它归因为尾撞耗散：本次甚至没有尾撞。实际摩擦存在向上分力，也不意味着总脚力向上或板必然腾空。

## 能量与执行时序核对

伺服力在每次 `mj_step` 后、额外诊断 `mj_forward` 前读取，对应本次真正执行的驱动力；几何状态另在 forward 后读取，未混用两个时刻。

- 夹具每轴实际力乘以实际滑动位移累计：正功 **12.318027 J**、负功 **−9.436059 J**、净功 **2.881968 J**；峰值实际伺服力 **136.637 N**，未达到 250 N 限幅。
- 板动能加重力势能增加 **0.450387 J**，含夹具在内的系统机械能增加 **1.639748 J**；净驱动功与机械能变化相差 **1.242220 J**。该差包含软接触/摩擦、未显式计入的接触储能及数值离散影响，不能把它全归为木板材料耗散。大量驱动功也用于夹具自身升高与加减速。
- 将实际脚力、地面力和重力在每个执行间隔积分，与板质心总动量变化比较，世界 XYZ 最大残差 **5.96×10⁻¹³ N·s**。没有额外未入账的板驱动力。

## 可复核文件与边界

`summary.json` 为总指标，`states.json` 保存位置/速度/能量及完整最低点，`intervals.json` 保存实际驱动力/做功和脚板、地板合力，`contacts_execution_stage.json` 保存全部原生接触的 frame、6 维力、材料和穿透，`mechanical_fixture_scene.xml` 为独立组件模型。`fixture_rollout.npz` 保存每一步实际状态和实际夹具控制；`derived_mechanism_analysis.json` 补充接触时间、锥上界、各几何对穿透与位移分析。

从唯一初态按保存控制独立原生重放全部 160 步，`qpos/qvel`、每步执行伺服力、全部接触力/frame/distance 最大绝对误差均为 **0**。核验见 `independent_replay.json`。原板 XML SHA256 为 `b0275651d4ca6e8455e0a8cdcf65204078017007c8c3416635b2460050bfc17b`，组件模型和全部原板属性逐值核对保持不变；相等约束 0、mocap 0、板电机 0、`qfrc_applied/xfrc_applied` 均为零。

复跑唯一固定组件配置：

```bash
env -u PYTHONPATH -u PYTHONHOME CUDA_VISIBLE_DEVICES='' \
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  uv run --locked python scripts/local/check_ollie_tail_release.py \
  --out-dir logs/ollie_tail_release_reproduce_01
```

实现记录：首次执行前修正了 MuJoCo 伺服参数数组长度；首次完成动力学后，NumPy 整数 JSON 序列化错误导致结果未能保存，也未观察到结果。修正输出类型后，原参数与原路径精确重执行一次仅为恢复输出，不属于调参。随后 XML 导出 API 错误发生在全部数组/JSON 已保存后，仅重建模型补 XML，没有再运行动力学。总共只有一种预先确定的 probe；此后只有同控制独立重放。最初“正值力出现”标签已依据保存力改为明确的“净向上冲量正例=False”，没有改动实际状态与控制。

本组件不校准真实鞋底、砂纸、木板弹性或桥架；失败不证明所有合理上提路径都失败，瞬时正向力也不证明机器人能实现。真实 29 关节 PD 路线仍需独立完成板头接触维持、后脚释放、整板离地和接板落稳。本日志不生成或晋升 teacher，也不触发新训练或参数搜索。
