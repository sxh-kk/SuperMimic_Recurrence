# 78｜接触世界模型位置速度一致性诊断

本轮只在 CPU 读取72的真实数据和73已经保存的三个世界模型，重算预测、运动学残差、损失及梯度；**没有采集新控制分支、没有执行 optimizer 更新、没有修改 codec 或物理，也没有训练 actor**。

目前证据指向一个具体的表示问题：板位置和板速度可以通过独立位置修正项分别拟合，位置较准不保证速度正确。留出集上，两臂 H8 板速度误差为 **1.983/2.634 m/s**，同时每步位置修正达到 **22.757/30.418 mm**；真实数据按相同定义只需 **0.679 mm**。这说明模型有能力用位置修正补偿错误速度，不能证明该自由度是全部误差的唯一原因。未发现本轮相关的状态索引、坐标、单位或辅助头接入错误。

建议只保留为一项**未来待预注册的板位置梯形积分 codec 对照**；本轮没有实现或验证其学习收益。板 BPTT 仍关闭，完整物理 Ollie 仍 FAILED。

## 2. 实际实现：位置和速度之间存在独立修正

`JointWorldModel.step` 使用 `canonical(state) → DynamicsMLP → spec.integrate`，见 [learning.py](../src/supermimic/ollie/learning.py#L31)。73的辅助头共享 trunk，但没有改变状态路径，也没有把预测 force 写入 state 或仿真，见 [contact_learning.py](../src/supermimic/ollie/contact_learning.py#L67)。

当前92维状态的板字段为：世界 XYZ `71:74`，wxyz `74:78`，四轮角 `78:82`，世界 VXYZ `82:85`，板体系角速度 `85:88`，轮速 `88:92`。本轮核对 `root_response` 的这些切片和世界/体坐标变换，没有发现字段错位。94维 canonical feature 与90维 delta 维数匹配。

默认 `explicit_integration=True`、`dt=.02`。板更新的准确形式是：

```text
v_next = v + R_heading(board_quat) * dv
p_next = p + dt * v_next + R_heading(board_quat) * dp
```

`dv`、`dp` 是网络输出乘各自尺度后的量，`dp` 不由 `dv` 唯一决定，见 [JointStateSpec.integrate](../src/supermimic/ollie/state.py#L195)。板 `dv` 输出尺度 `.3 m/s`，`dp` 输出尺度 `.01 m`；`.01` 是乘数，**不是硬上限**，MLP 原输出可超过1。位置和速度误差尺度分别 `.05 m` 和 `1 m/s`，见 [state.py](../src/supermimic/ollie/state.py#L167)。

机器人原 `StateSpec` 也明确保留独立位置修正，见 [state_spec.py](../src/supermimic/world_model/state_spec.py#L93)。因此本轮所说的“一致性缺口”是现有模型表示允许的行为，不能写成误删积分、索引错误或发现了实现与其声明不一致。独立修正也可以近似离散积分误差，不能仅因它非零就判错；关键是实际量级及其与错误速度的关系。

其它排查：

- canonical feature 绝对值最大训练4.67447、留出4.64294，没有观察到输入数值爆炸。
- 原生板世界速度最大分量训练 `.542471 m/s`、留出 `.525673 m/s`；预测2 m/s级误差并非原始速度本来如此。
- 原生端点板根 VZ 与板 COM VZ 的差，RMS `2.6562e-6 m/s`、最大绝对值 `3.8557e-5 m/s`，不能解释本轮速度误差。本报告仍统一使用**板根**位置和世界速度，不将两者混称。
- H8 训练/推理是自由递推，只有初始真实状态，没有把真实中间状态误接入模型。下文 teacher-forced 检查是另一个明确标注的诊断。

## 3. 与未训练常速初值比较：错误集中在146

以下所有 XYZ/VXYZ 都是向量 RMSE：对分支的三个轴平方误差求和、再平均开根，**不是各轴 RMSE 的平均**。`initial` 的状态末层为零，板保持初始速度并按该速度积分，所以这里把它称为“未训练常速初值”；它不是已经学会接触的基线。

| 留出 H8 指标 | 未训练常速初值 | state+paired | 加接触辅助头 |
| --- | ---: | ---: | ---: |
| 板 XYZ RMSE | 41.29490 mm | 32.53746 mm | 22.92936 mm |
| 板 VXYZ RMSE | .493278 m/s | 1.982780 m/s | 2.634163 m/s |

两臂位置误差下降，但速度明显劣于未训练常速初值；不能只报位置改善。

| 留出 anchor / H8 指标 | 未训练常速初值 | state+paired | 加接触辅助头 |
| --- | ---: | ---: | ---: |
| 146，板 XYZ | 57.47379 mm | 36.03718 mm | 27.35109 mm |
| 146，板 VXYZ | .693762 m/s | 2.792153 m/s | 3.722879 m/s |
| 160，板 XYZ | 10.35861 mm | 28.61284 mm | 17.41923 mm |
| 160，板 VXYZ | .073083 m/s | .258287 m/s | .133415 m/s |

两个 anchor 的31分支数量相同，总体严重速度回归主要来自146；160也不能称通过：其两臂位置和速度仍比未训练初值差。这个分解避免把总体误差误写成所有留出状态一概以同样幅度发散。

为区分单步拟合与递推放大，另外把每个真实 `state[k]` 输入已有模型，只预测下一步，用真实 `action[k]`，不更新权重。**这不是73的训练方式，也不是可部署预测。**在留出集最后一步真实 `state[7] → state[8]` 上，板 VXYZ RMSE 依次为 `.049413 / .637989 / .491227 m/s`；在全部8个真实输入单步上，为 `.081281 / .678950 / .517198 m/s`。

真实输入诊断比自由递推的1.983/2.634 m/s误差小，但训练后局部绝对动力学本身已经比常速初值差。证据同时包含“单步偏差”和“递推放大”，不能只归因于第8步累计或只归因于事件覆盖不足。

## 4. 真实 dp 与模型 dp：同一定义下比较

令 `p[k]` 为世界坐标板根位置、`v[k]` 为世界板根速度。用保存的状态直接计算：

```text
c_native[k] = p_native[k+1] - p_native[k] - dt*v_native[k+1]
c_pred[k]   = p_pred[k+1]   - p_pred[k]   - dt*v_pred[k+1]
dt = .02 s
```

`c_native` 表示真实20 ms转移相对“新速度半隐式积分”需要的修正；它允许物理子步、加速和接触离散化造成非零值。`c_pred` 按当前 codec 等于旋转到世界系的独立 `dp`，只存在浮点舍入差。模型第0步的前状态是真实初态，后续前状态都是自己的预测；未注入真实中间状态、未事后裁剪或重积分预测。

| 所有8步的修正统计 | 向量 RMS | 最大单轴绝对值 |
| --- | ---: | ---: |
| 真实训练数据 | .800753 mm | 2.387132 mm |
| 真实留出数据 | .678814 mm | 1.459498 mm |
| state+paired，留出 | 22.756841 mm | 40.283639 mm |
| 加辅助头，留出 | 30.417555 mm | 51.714618 mm |

“最大单轴”与下节 oracle 的“最大向量范数”口径不同，不互换。H8末次修正在146的向量 RMS为 `48.649234 / 63.848633 mm`；160则为 `1.045603 / 1.336424 mm`。这与速度误差集中在146一致。

因此，厘米级的独立修正足以让预测位置保持相对较近，而预测速度很差。它是**已测到的补偿通道和不一致现象**；没有通过改变该通道做因果干预，故不宣称它是唯一原因，也不宣称把它删掉后模型必然更准。

## 5. 使用真实未来速度的 oracle：只核验积分近似误差

oracle 从每条分支的真实 `p[0]` 开始，读取全部8步**真实未来速度**；没有使用学习到的速度。两个固定规则为：

```text
p_SE[0] = p_TR[0] = p_true[0]
p_SE[k+1] = p_SE[k] + dt*v_true[k+1]
p_TR[k+1] = p_TR[k] + .5*dt*(v_true[k] + v_true[k+1])
```

SE为不含独立 `dp` 的新速度半隐式积分；TR为梯形积分。最终和真实 `p_true[8]` 比较：

| H8 位置误差 | 向量 RMS | 最大向量范数 |
| --- | ---: | ---: |
| 训练，SE oracle | 1.881418 mm | 4.000636 mm |
| 训练，TR oracle | 1.020756 mm | 1.927337 mm |
| 留出，SE oracle | 3.851620 mm | 6.426246 mm |
| 留出，TR oracle | 1.190012 mm | 2.050920 mm |

逐步梯形闭合残差 `p_true[k+1]−p_true[k]−.5*dt*(v_true[k]+v_true[k+1])` 的向量 RMS为训练 `.350652 mm`、留出 `.230103 mm`，最大向量范数分别 `1.502676/.634886 mm`。

这些数字只说明：在72这批有限接触数据中，**若已知真实未来速度**，梯形位置更新的离散近似误差较小。oracle 使用了预测时不可得的信息，不是世界模型预测分数，不能将1.190 mm写成“新模型已达到的误差”，也不能把它当模型改进幅度。速度预测、接触切换及可学习性仍未验证。

## 6. 配对损失不能替代绝对动力学

73固定配对响应取同初态下的正负动作差，H1/H8均约束；它不会直接约束两条预测**共同的速度偏置**。响应相减可抵消共同偏置，因此训练响应好不保证绝对状态好。现有代码的配对尺度与42一致，H1 board-VZ为 `1e-4 m/s`，H8为 `.01 m/s`；本轮没有重新选择尺度。

只对现有权重计算一次全训练集损失及主 dynamics 参数梯度，没有 `optimizer.step`：

| 训练集诊断 | state+paired | 加辅助头 |
| --- | ---: | ---: |
| 状态损失 | .0496215 | .0517443 |
| 配对损失 | .2267650 | .2350139 |
| 状态项梯度范数 | .3538880 | .5373399 |
| 配对项梯度范数 | 1.2640636 | 6.6869907 |
| 两项梯度余弦 | +.1568084 | +.0647778 |

配对项梯度范数分别约为状态项3.57/12.44倍，方向接近正交，**没有测到两项梯度整体相反**，不能写成已证明的破坏性梯度冲突。它提示小响应尺度在当前局部目标中有较强影响；不是授权本轮调权重或减配对项。

留出配对损失为 `8.797109/8.836784`，其中单独 H1 board-VZ项贡献 `7.480385/7.442509`。小尺度没有让留出真实响应自动变对。73已有留出 board-VZ结果仍为：

- H1响应 RMSE `.00189488/.00189008 m/s`，零响应基准 `.00176792 m/s`；gain `−.01035/−.00621`，符号率 `36.67%/43.33%`（30对）。
- H8响应 RMSE `.02200949/.02409580 m/s`，零响应基准 `.00365429 m/s`；gain `−.02241/+.01007`，符号率均 `37.93%`（29对）。

两臂均劣于忽略动作的响应基准。这里 gain 为 `Σ(pred_response*native_response)/Σ(native_response²)`；符号只计真实绝对响应 `>1e-6 SI`，没有逐样本除以微小响应。不能因辅助标签 MSE较低而开放板想象梯度。

## 7. 与33—42已有证据的关系

[33离线预训练](33_Ollie真实数据世界模型预训练.md)曾改善位置误差，但未认证动作梯度；[36原生梯度审计](36_Ollie世界模型动作梯度审计.md)中模型 autograd 与自身有限差分相对误差小于 `.00029`，仍有真实板响应方向不可信的反例。[39空中数据复核](39_Ollie空中数据世界模型梯度复核.md)加入空中源后，一些位置指标改善，模型自身 autograd 核验小于 `.00019`，板动作响应仍未校准。

[42配对响应对照](42_Ollie配对动作响应世界模型对照.md)曾使训练 H1 board-VZ gain约1.018，但留出 H8 gain仍为 `−.0228`、符号率 `48.3%`，劣于零响应基准。73新增明确接触辅助监督后，留出问题仍在。因此“再多拟合几轮”“只看训练响应”“只补force标签”都不能直接构成板 BPTT 可信证据；本轮诊断没有重新证明 autograd 对所有输入都正确，也没有把历史局部结论扩大成全局保证。

另外保留了一项次要输入表示诊断：只将已有模型输入的四轮角同时加/减 `2π`，不改其它量，模型 H8板速度可显著变化；归档见 `wheel_phase_gauge_sensitivity.json`。圆轮几何的周期等价没有由当前原始轮角 MLP表示强制满足。但146初始轮角约 `−.145/−.127/−.189/−.205 rad`，处于训练范围，不能据此断言本次146发散就是轮角超分布。本项不是 native 新动作试验，也不作为本轮第二条修复计划。

## 8. 仅保留一个未来候选：板位置梯形 codec

下一次实施时，最小可检验变更是**仅对板根位置**使用：

```text
v_next = 原有速度解码结果
p_next = p + .5*dt*(v + v_next)
```

忽略原板3个独立 `dp` 输出通道，保留原 state92/delta90网络宽度、机器人解码、板旋转/轮状态解码、物理、μ=.9、原29动作、72数据/分组、固定损失尺度和配对项。codec需显式 opt-in和版本元数据，不能让旧checkpoint静默改变含义。这属于 SuperMimic 世界模型表示的一项监督对照候选，不引入预测力驱动、物理残差或外部控制算法。

必须在运行前预注册唯一 WM对照、预算和比较口径，分别报告 H1/H8绝对状态、位置速度闭合、真实成对 gain/符号及零响应基准；不能看完留出再调整尺度或反复搜索。**这项改动本轮没有写代码、没有训练、没有任何已验证性能收益。**真实 oracle只支持“值得检验的离散近似”，不保证错误速度会因表示约束而学好。

即使未来该对照改善72附近状态指标，原数据的 tail/nose/flight覆盖仍为0，不足以认证 Ollie事件梯度或解锁 board BPTT。当前优先任务仍是76的原生释放机制数据试验；本报告不启动新 WM拟合或 actor更新。
