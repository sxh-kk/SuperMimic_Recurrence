# 原片参考的物理平衡反馈对照

2026-10-23。入口 `scripts/local/probe_ollie_reference_balance.py`。这是原片extended参考的PD控制基线，使用原片左前/右后脚和约-75°根朝向；与generic控制基线的左后/右前站姿区分，**不是学习策略或SuperMimic结果**。

## 实际执行

全部候选从同一个参考首帧、零初速开始，只写29个机器人PD目标。固定偏置来自准备段025_gated；每20ms计算一次踝反馈并保持8×2.5ms，没有板驱动、外力或中间状态覆盖。仅在至少一脚存在>0.1N真实足板接触时启用反馈。

根姿态去掉初始heading，根角速度从body系转到world后投影；COM相对双脚中心的水平误差、根水平速度和姿态/角速共同生成姿态修正，再投影到四个真实踝关节的world轴。正号给关节目标加修正，负号为独立反方向对照；实际目标始终裁剪到原关节范围内侧0.005rad。四个踝修正上限为pitch±0.35/roll±0.15rad，不改变真实关节或力矩限位。

第一组为无反馈加18个正/负号×scale0.25/0.5/1×速度增益0.16/0.5/1，共19候选。第二组为无反馈加9个正号×scale1.5/2/3×速度增益0.5/1/2，共10候选。每个候选连续跑完整5.14s，按真实逐物理步接触判断，跌倒不重置。所有候选均失败，没有合格Ollie。

## 结果

- 无反馈固定偏置：首次机器人触地2.015s。
- 第一组最佳：正号、scale1、速度增益1；首次触地2.755s，0～2.76s最低直立余弦0.6656，整段最大穿透21.07mm，仍未完成预蹲课程。
- 第二组最佳：正号、scale1.5、速度增益2；首次触地2.745s，课程最低直立余弦0.6852，最大穿透17.07mm，仍失败。继续增加增益没有单调改善。

物理视频和完整实际状态位于 `logs/ollie_reference_balance_probe_01/02`。每组保存 `all_candidates.json`、最佳的 `actual_rollout.npz`、`rollout.mp4` 和结果，第二组另保存逐子步 `contacts.csv`。视频明确标为未训练PD反馈probe及FAILED。实测回放检查包含258×92状态、257×29实际控制、真实目标限位与有限性，见各组 `replay_check.json`。

这些结果支持反馈方向修正有帮助，但不能认为简单增益网格已经解决支撑、接板或原片动作跟踪。没有通过完整准备课程的候选不能作为BC成功教师。

## 全身碰撞复核发现

在相同extended运动学参考中逐帧运行真实模型完整碰撞检测，发现140个超过5mm的接触点。最严重的恢复段为视频6.57s的left_hand与left_thigh穿透67.31mm；预蹲段视频3.72s的left_wrist与left_thigh穿透49.13mm。超过1mm的首个自碰样本在物理2.32s/视频3.48s。

数据保存在 `logs/ollie/contact_extended/full_collision_audit.json` 和 `all_self_contacts_over_1mm.json`。之前文档17/22通过的是明确限定范围的足板几何QA，没有认证全身无自碰。这次补全身检查发现，该参考还不能作为完整物理可行的目标。原固定偏置在2.015s已先触地，所以不能把最早失稳全部归因于后续自碰；载荷补偿/平衡与自碰修复都需要处理。

下一分支仅调整14个手臂关节，保留根、腿和板，减少手臂对腿/躯干的碰撞，并重新检查全部几何与时序。实际碰撞不关闭，不通过隐藏模型碰撞来让参考看似可执行。
