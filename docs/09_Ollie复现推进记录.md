# 指定 Ollie：链路实施与验证记录

2026-10-23，用户要求将 `video/ollie.mp4` 的方案实际打通，持续推进到可查看的物理仿真视频；随后明确授权直接下载 SMPL-X 等所需模型和依赖，无需逐项确认。本文持续追加实际结果，方案依据见 [视频分析](07_Ollie视频分析与实施方案.md)。

## 实施约定

- 目标保持 29 DoF G1 与被动滑板的真实连续物理执行，SuperMimic 人板联合扩展为目标算法。
- 人体前端、GMR 和板追踪使用独立环境，不升级系统驱动，不破坏已验证的平地训练环境。
- 运动学参考、用于物理可行性检查的轨迹控制、学习策略分别命名；阶段调试视频不冒充最终复现。
- 正常重力、板无主动关节 / 隐藏推进或吸附；最终完整回合中不在起跳、腾空、落地之间重置。
- s=1.5 慢放为用户估计，保留时间倍率与米制尺度假设，人体 / 板 / 接触必须共用时间和世界坐标。
- 每批代码测试完成后使用中文提交并推送 `sxh-kk/SuperMimic_Recurrence`；模型、输入视频、派生数据、运行日志和 MP4 留在忽略目录。

## 第一批：实际部署与独立组件

已开始并行实施：

1. **视频人体恢复**：固定克隆 GVHMR，独立 Python 3.10 / Torch 2.3 CUDA 12.1 环境。公开模型下载与固定版本 / 哈希记录在本机；SMPL-X NEUTRAL `.npz` 已下载且哈希匹配。为保留滑板交互，禁用普通脚锁地面后处理；不依赖 SMPL-H 替代。具体执行见文档 10。
2. **被动板物理场景**：自由板、四个无驱动轮、分段板头尾碰撞形状，与原 G1 组合；优先原地 Ollie，不增加暂时无关的 truck 转向。属于根据任务新建的简化物理模型，不能标成完整 HUSKY。具体检查见文档 11。
3. **联合状态 / 参考契约**：机器人原 71 维状态加自由板与四轮的 21 维，名义状态 92 维；按模型地址映射，保持原平地代码契约。参考记录显式物理时间、视频时间、阶段、接触和置信度。见文档 12。
4. **板图案二维追踪**：独立 OpenCV 环境，对人工给定的少量板面图案角点做双向光流 / RANSAC 传播；对失败保留缺失与置信度，不输出虚假的全帧可靠三维轨迹。见文档 13。

本段是实施开始时的状态，尚未声称人体重建、G1 重定向、联合训练或最终动作复现成功。后续以各验证结果追加为准。

## 联合状态组件已验证

独立92维状态、按名称/地址读写、90维可微更新和94维特征已实现；原平地契约未修改。新CPU测试9项、原StateSpec/GAE基线2项通过，并与实际G1+板模型进行92维pack/unpack往返。参考格式要求来源、双时间轴、接触未知值和置信度，详见 [联合状态实现](12_Ollie联合状态实现记录.md)。目前仍未接入联合世界模型或学习控制器。

## 人体恢复与被动场景实际打通

- GVHMR 的真实 YOLO → ViTPose → HMR2 → GVHMR → SMPL-X FK → 骨架叠加已完成，233帧 / 30Hz，约29.08秒，Torch分配峰值3.07GiB。结果是人体恢复，不是机器人执行，见 [前端记录](10_视频人体恢复接入记录.md)。
- 坐标审计发现原世界系为Y-up、地面未对齐；人体反推camera/world变换逐帧变化明显，不能当作实测固定相机外参去驱动板。现统一保留camera-space人体/板证据，使用单一工程估计的Z-up变换，再校正人板关系。
- 真实29DoF G1+自由板+四轮场景通过重力、自由飞行、被动滚动、尾地碰撞、足板接触、模型重载与EGL预览，详见 [物理记录](11_Ollie物理场景记录.md)。碰撞峰值穿透约5–7mm，仍待调参；尾碰撞测试的人工初始角速度不冒充机器人Ollie。
- GMR的原始与共同坐标分支已实际执行，258帧 / 50Hz均有限且关节限位通过；仍有较高瞬时关节速度、脚板关系和空间尺度问题，接触参考校正继续进行。

## GPU 联合动力学训练原型已运行

G1+板场景进入MuJoCo-Warp，8环境CUDA graph检查通过；64环境实际采集3072条站板/蹲起物理转移，500次模型更新通过。独立回合留出损失0.39182→0.02967，已检查模型BPTT梯度路径。这不代表Ollie策略已经训练成功，也不代表起跳/落地预测已可靠，详细配置及边界见 [联合模型记录](16_Ollie联合模型训练记录.md)。

## 三维板参考与接触校正实际完成

板中央图案9帧完整透视候选的重投影RMSE中位数1.061px；近地面帧采用明确标注的地面/时序先验和中心观测，缺失没有冒充图像测量。保留IPPE双解及人工尺寸、相机和坐标假设，晚段板端仍有17–20px残差。完整258帧50Hz运动学参考通过碰撞包络不穿地检查，详见[板拟合记录](13_板图案追踪与三维拟合记录.md)。

人体和板在共同坐标中进入真实G1的足底几何校正，得到 `data/ollie/joint_reference_50hz.npz`。站稳窗每脚125样本：最大足板支持间隙0.820mm、平面anchor误差0.149mm；全段足板最大穿透1.394mm，关节限位通过，最大关节速度12rad/s。根平移有明确记录的校准，参考轮运动未观测。详见[接触参考记录](17_Ollie接触参考校正.md)。这些是运动学几何检查，下一步仍须只控制机器人、连续前向仿真验证。

## 当前实际状态与重要更正

模型资产、人体恢复、板三维拟合、G1重定向、联合参考、GPU真实采集、世界模型/BPTT策略更新、原生CPU接触评测和MP4对照均已实际运行。**完整Ollie物理复现尚未成功**，不能用运动学参考中看似完成的动作代替真实控制结果。

- 两次30轮学习共采集184320+491520条真实训练转移，均保存结束。第二轮实际CPU筛选最优为第20轮，首次机器人触地2.135s，仍未起跳；模型和权重的适用限制见[训练记录](16_Ollie联合模型训练记录.md)。最新三栏视频为本机 `logs/ollie_comparison/pilot02_best/comparison.mp4`，右栏明确FAILED。
- 原片准备段固定偏置通过1.34s真实足板接触复核；正方向踝反馈能延后预蹲触地，但仍未通过完整预蹲课程。短时没摔倒不等于静止或长期稳定，详见文档20/24/26/27。
- **撤回“全板离地165ms”的错误表述**：旧PD11指标是四轮高度与无生成接触的17段累计代理，最长25ms、最大全板真实间隙0.419mm，未满足连续40ms和>5mm包络离地。PD14的旧220ms同样不能认证合格腾空。旧视频错误标签已留历史文件，当前视频改为失败/未认证标签。所有这些尝试始终FAILED，详见文档14/28。
- 补全身检测发现旧参考腕/手穿腿，最大67.31mm，先前足板QA没有认证这个范围。仅调整14个手臂关节后，258个50Hz样本及2057个加密姿态自碰均降到1.474mm以内，根/腿/腰/板保持不变。新分支为 `data/ollie/self_collision_corrected/joint_reference_50hz.npz`；仍有帧间足板插值6.990mm残差，不能称连续全几何通过，详见文档25。
- 新训练默认拒绝任何50Hz阶段reset姿态全身穿透超过2mm。旧两轮随机阶段数据中含非法互穿初始化，不能将其留出误差当成正常起跳/落地可靠性证明；历史数据保留，下一轮须以修复参考重新采集。
- s=2.0已全链路重新生成并对照，仍在1.025s首次触地；未替换原1.5假设。更换倍率不能单独修复控制、单目重建和参考动力学不一致，详见文档19/21/22。

当前优先在修复参考上验证接触静力/准静力前馈和真实状态反馈，先获得连续准备/预蹲的合法物理教师，再接踩尾、起跳、接板与落地。接触力求解只转换为机器人控制，不把求解力直接施加到板或根；最终以实际连续物理视频和统一全包络接触判据验收。
