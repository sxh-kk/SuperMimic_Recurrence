# Ollie 真实翘尾接触参考修复

新建了后脚实际覆盖翘尾的运动学参考。正式 v3 通过真实足胶囊、倾斜尾面和全身碰撞检查；尚未通过真实物理准备段，更不能称为起跳或 Ollie 成功。原有参考与教师均未覆盖。

## 输入、输出与范围

- 脚本：`scripts/video/repair_ollie_tail_contact.py`。
- 输入：`data/ollie/air_relative_video_timed_v1/joint_reference_50hz.npz`，SHA256 `941f748cf3b13edbcf60dd20f2db41810cee2cbd1e9b4dccba1e3b1d4b5a71f5`。
- 正式输出：`data/ollie/tail_contact_v3/joint_reference_50hz.npz`，SHA256 `9ef91bcbac47ab919d80525b1330baed9e520c36cb02089bc7793d064189c653`。
- 机器诊断：`logs/ollie/tail_contact_repair/v3/result.json`、`solver_frames.json`、`surface_audit.npz`。
- 当前阶段是显式工程接触先验与运动学修复。单目视频没有给出已测准的 −0.32m 压点或接触力。

仅优化机器人根、12个腿关节和3个腰关节。14个手臂关节的位置、速度逐值保留；板的全部21维 state、旋转、时轴、轮角与速度、9个可靠PnP节点逐值保留。phys≥3.16s整个机器人与板state均与输入逐值相同。

## 具体约束

左脚在 phys0..2.76s 维持原来的中心板锚点 X=+0.2050207m；右脚在0..2.90s改为 X=−0.32m、Y=+0.0224529m。左脚释放后保留源参考世界轨迹的软约束，并不继续焊到板上。

右脚接触的是实际 `board_tail` 碰撞盒的12°倾斜上表面。优化使用7个真实足胶囊沿该面法向的最低支持值，目标间隙0.8mm，脚朝向的法向也对齐该尾面。没有使用无限平板 `BOARD_TOP_OFFSET=.006` 代替翘尾。

接触窗口来自原片定性证据：video4.3377s后鞋仍在尾部，4.4211s仍接近尾面，4.5045s已经明显离开。因此默认 phys2.90s 为保守工程窗口，2.94s只能作为显式边界敏感性分支。video=1.5×physics 仍是假设倍率。

右脚释放后，把最后一帧修正相对源参考的位姿差以五次平滑函数衰减，到3.14s消失，不在空中继续强制脚踩板。此释放是运动学衔接，不证明速度/加速度可由真实关节力矩实现。

关节使用模型真实限位及邻帧12rad/s约束。碰撞约束同时检查当前节点和前一个20ms区间内的7个插值点，避免只有50Hz节点无碰而中间穿身。手臂角度保持不变，避碰由根、腿和腰承担。

## 实际检查结果

完整258帧参考按2.5ms插值检查2057个姿态，保留所有原碰撞几何与碰撞掩码：

- 自碰最大1.312586mm；机器人与板最大0.198150mm；地面最大0.107736mm。所有类别均无>2mm穿透。
- 真实关节限位最大违规0；所有29关节相邻帧最大速度12.000000rad/s。
- 左脚中心板窗口1105个致密样本，全部存在到真实盒上表面<3mm的胶囊最近点，最大距离0.912747mm，XY锚点最大误差0.115555mm。
- 右脚尾面窗口1161个致密样本，全部存在到真实尾盒上表面<3mm的胶囊最近点，最大距离0.997517mm，最小胶囊到尾盒有符号距离+0.076399mm，XY锚点最大误差0.444494mm。
- 右脚 site X 范围[−0.3202937,−0.3198656]m。根平移最大改动0.107825m。

足部允许边缘悬出盒面。不能要求任意一个“沿面法向最低的胶囊端点”总在盒内：近乎平行的胶囊轴会使最低端点在两端切换。当前检查另逐个查询7个胶囊与真实有限盒子的最近点，要求至少一个最近点确在所选上表面、距离<3mm，并检查全部碰撞，避免把无界平面重合误判成踩中翘尾。

## 失败分支与版本关系

首版 `data/ollie/tail_contact_v1/` 虽能踩尾，致密插值在2.390s出现左手腕-左大腿2.501966mm穿透，因此明确不通过。没有放宽阈值。加入相邻区间碰撞约束后得到 v2/v3。

v2 SHA256 `24a1f129e3702f9de69152ea6deb8a1363877a507eb246f934e41551168072b7`。v3只是格式、可读关节名、当前QA与provenance元数据修正，两个文件所有7组数值数组——两时轴、robot/board state、phase、contacts、confidence——逐值完全相同，92维state最大差严格0。证明文件：`logs/ollie/tail_contact_repair/v3/v2_v3_exact_state_proof.json`。这允许在明确此证明的前提下关联v2实际物理诊断，但不能把旧941f教师或BC视为与新准备段兼容。

## 尚未解决的动态问题

全片根最大速度3.168233m/s，最大加速度66.525844m/s²；这里只约束了关节速度和几何，没有证明根轨迹动力学可行。原板高的过渡和空中COM接缝仍有独立问题，需要后续弹道检查，不应据此增加外力。

准备段 pelvis upright 最低0.8239075，发生在2.38s；源941f同窗最低0.8258858。两者都低于现准备教师的0.85门槛，因而即使完美跟随这些姿态，也存在参考与准备验收的冲突。不能降低真实验收掩盖它。后续可另建显式upright约束分支，用腰补偿尽量保留躯干动作并重新进行全部几何检查。

根代理已用实际倾斜接触面静力求解器对v2运行三组连续原生物理准备：scale0.45/0.25/0.65均FAILED。QP找到静力解不等于真实控制能跟随；实际接触仍由MuJoCo产生，QP力没有直接注入。详细动态结果由对应物理记录维护，本参考只宣称运动学检查通过。
