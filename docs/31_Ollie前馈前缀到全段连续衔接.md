# Ollie 前馈前缀到全段连续衔接

## 实际结论

以 [准备/预蹲前缀教师](29_Ollie接触前馈控制.md) 的真实动作连续执行到物理 2.76 s，随后衔接原片参考 PD 与少量明确的蹬伸/踩尾目标脉冲，实际完成了五组 **5.14 s 不间断原生物理仿真**。五组在 2.76 s 的 92 维状态与教师末状态最大差均为 **0**，没有从深蹲重新摆位、清除速度或重新初始化板。

**所有完整 Ollie 评测均失败。** 最晚首次机器人触地为 3.2225 s；该组之后发生的滑板短暂离地来自机器人已经倒地后的相互作用，不能算完成踩尾、同步起跳或接板。没有生成全段教师，也未训练策略。

当前空中人板相对参考还存在明显漂移，不能继续盲目优化控制器去追它。本轮保留完整失败轨迹和真实视频；接下来应先审查原片无支撑阶段的联合参考，或另行建立真实物理 pop 控制，再连续衔接验收。参考问题与前缀末端动量、控制器不足同时存在，不能凭本次五组试验把失败单独归因于某一因素。

输入：

- 前缀 `logs/ollie_quasistatic/corrected_static_final_v2/feedback_0.45/teacher.npz`，SHA-256 `becf8edd26596b6ae858418e3a5f20f1f8bea5ab42c89c862d29d1347dd1d738`。

每组回合只有一次初始化，从原参考首帧和前缀零初速开始。前 138 个 20 ms 动作逐值回放已验证教师动作；2.76 s 后保留真实位置、速度、板姿态、轮运动与接触状态，继续同一个 MuJoCo data。

后续目标是 `qref + kv*qvel_ref/kp`，将前缀最后静力力矩对应的 `tau/kp` 在 0、0.16 或 0.32 s 内平滑淡出。这是上一阶段关节前馈的时序退出，**没有在腾空阶段重新假设双脚/四轮静力支撑**，也没有把计算出的点力施加到模型。

只有真实板上表面向上支持 >1 N 的脚继续接收正方向踝反馈；失去上表面支持时对应脚的反馈关闭。所有目标仍只通过 29 个 G1 位置驱动器执行，按真实关节目标范围裁剪，原力矩限位、增益、质量、重力、碰撞和摩擦均保持。

两个 pop 对照仅增加物理 2.80～3.04 s 的平滑关节目标脉冲：双膝减少屈曲、髋部向伸展方向运动，并将后脚踝旋转投影到真实世界关节轴。幅度为 0.3 或 0.6 rad，再受实际关节目标范围约束；它们是明确的未训练 PD 控制试验，不是已学习的策略或经全局优化的动作。

从原参考 FK 核实：**左脚是板 +X 前脚，右脚是 -X 后脚**；generic 物理基线的左右分工相反，不能直接复制其关节脉冲。

## 空中参考的几何限制

当前显式踩板工程先验截止视频 4.15 s，即物理约 2.7667 s。之后没有双脚焊接约束，这是合理的；但人/板相对关系也不能任由不同单目恢复分支漂移而直接当作可靠接板目标。

在同一真实模型上计算 foot site 的板局部坐标，板上表面约 z=0.006 m：

- 物理 2.76 s：左约 `[0.205,-0.025,0.005]` m，右 `[-0.207,0.022,0.005]` m。
- 物理 3.10 s、视频 4.65 s：左 `[0.192,0.381,-0.074]`，右 `[-0.323,0.335,-0.030]`。
- 物理 3.20 s、视频 4.80 s：左 `[0.156,0.325,-0.303]`，右 `[-0.276,0.340,-0.232]`。

可见空中段脚相对板侧偏约 0.3～0.38 m，还可能低于板局部平面 0.2～0.3 m。这不是足板压力证据，但足以说明当前联合参考尚不能作为可信的贴板/接板轨迹。应检查 stance 校准在无 contact 段回归 raw 时的根漂移、GMR 米制缩放、固定共世界变换与板参考误差；不能通过暗中焊脚或强造接触修好。

新的空中参考分支应优先保留已验证前缀，明确记录改变的参考 hash 和相对几何，再在同一真实末状态上做连续物理复核。若为避免突变必须改变前缀末端所用的未来目标，应建立教师数据新副本、显式更新未来目标与来源并重新训练初始化，不能为复用BC而保留不可行参考。原始参考、前缀教师与本轮失败记录不应覆盖。
