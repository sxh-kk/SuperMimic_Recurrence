## 目前效果

已学到部分身体动作跟随和长时间维持姿态的能力，但全局轨迹 / 朝向偏差仍明显，倒地再起身等复杂转换较弱。一小时属于早期基线，尚无论文指标复现结论。这里评测的是已参与训练的 LAFAN1 40 段动作，不是未见视频泛化，也不是 Ollie 控制。

采用修正后的逐片完整时间预算：每片从首帧开始，关闭观测 / 动作 / 重置噪声与域随机化，seed=0，40 个并行环境，每段仅评一次。失败阈值沿用根高度 / 倾斜终止；没有触发阈值不等于位置和姿态准确。

| 指标 | 本次结果 | 含义 |
| --- | --- | --- |
| 到达片尾且未提前失败 | 31/40，77.5% | 按当前终止阈值判定 |
| 提前失败 | 9/40 | 失败片段也计入总成绩 |
| 总时间步覆盖率 | 91.12% | 执行步数 / 全部片段总预算 |
| 各片覆盖率均值 | 89.11% | 每段等权平均 |
| 执行前缀归一化回报均值 | 0.5132 | 只对实际执行时长平均 |
| 整段预算归一化回报均值 | 0.4563 | 失败后未执行部分按零奖励 |
| 按整段步数加权回报 | 0.4670 | 长片权重更大 |

回报是组合奖励指标，**不能解释成动作准确率百分比**。躯干锚点 `torso_link` 的全局位置 / 方向奖励均值约 0.000416 / 0.001174，各自理论正奖励上限为 0.01；相对身体位置项约 0.01853，上限为 0.02。结合对照画面，可判断局部身体跟随优于全局轨迹 / 朝向控制；指数奖励不能直接换算成米制误差。奖励配置名沿用 `motion_global_root_pos/ori`，实际以躯干锚点计算，失败终止则以 pelvis 判定。

- CPU fake-env 的 7 项测试通过，覆盖 1 / 2 / 5 槽混合队列、提前失败、末步失败、意外超时和保存指标。新导出脚本 Ruff / 帮助入口通过，1 秒 EGL 冒烟和以上三段实际视频导出通过。
