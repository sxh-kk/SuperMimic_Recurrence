# Ollie 板图案追踪与三维拟合

2026-10-23。输入为 `video/ollie.mp4`，原始哈希与时间事实见文档 07。此组件提供二维证据和带不确定性的三维运动学参考；投影吻合与几何不穿地均不代表真实动力学执行成功。

## 已实现

`scripts/video/track_board.py` 读取 ffprobe 原始 PTS，用少量人工目视的板面图案四角作种子，利用 [OpenCV 光流](https://github.com/opencv/opencv/blob/5.x/doc/tutorials/others/optical_flow.markdown)与 RANSAC 传播。检查前后向误差、内点、凸性、面积与最大位移，丢失后停止该传播，不用插值冒充观测。近乎侧对镜头的准备段使用相似变换，避免薄图案的单应矩阵病态放大；图案清晰的空中 / 落地片段使用单应变换。

种子在原始帧 0、119、128，帧号从 0 开始，四角顺序为远侧尾端、远侧头端、近侧头端、近侧尾端。标注针对中部红白图案，不是板外轮廓；坐标是目视近似，受脚遮挡和透视影响，并非真值。种子数据保留在 `data/ollie/board_image_seeds.json`，不上传派生输入数据。

输出逐帧原始视频时间、`t_physics=t_video/1.5`、图案四角、置信度、种子来源、内点和缺失标记。时间倍率仍为待验证估计。

## 本机安装与调用

独立环境 `.cache/board-cv`，Python 3.12.13；固定 NumPy 2.2.6、SciPy 1.15.3、opencv-python-headless 4.12.0.88、Pillow 11.3.0。未往训练 `.venv` 注入 OpenCV。

```bash
uv venv .cache/board-cv --python 3.12
uv pip install --python .cache/board-cv/bin/python -r scripts/video/requirements-board-cv.txt
.cache/board-cv/bin/python scripts/video/track_board.py \
  --video video/ollie.mp4 --seeds data/ollie/board_image_seeds.json \
  --out-dir logs/ollie/board_tracking --slowdown 1.5
```

输出为本机 `board_image_observations.json` 与 `tracking_review.mp4`；后者仅是二维追踪核对视频，不是物理执行。脚本拒绝与源文件哈希不匹配的种子。

## 检查与边界

首版对 175 / 186 帧产生候选图案观测；11 帧缺失为 106–111 和 123–127，恰处于踩尾侧视 / 落地前遮挡等困难窗口。候选数不代表可靠恢复率，长距离传播的置信度会降低。已目视查看准备、预蹲、起跳、空中、落地和站稳抽帧。

检查发现薄图案用自由单应传播可能把形状拉长，故准备段改用相似变换并限制传播到原始帧 105。清晰腾空帧的图案仍能跟踪；接触切换关键时刻不能仅据这些点判定真接触。

二维输出本身仍在原相机图像坐标中，不能直接作为米制世界轨迹。[OpenCV PnP](https://docs.opencv.org/4.12.0/d5/d1f/calib3d_solvePnP.html)估计需要正确的三维—二维点对应和相机标定；下面记录实际完成的三维拟合及其剩余误差。

## 已运行的三维拟合

`scripts/video/fit_board_reference.py` 是独立 CPU 入口。读取原始 PTS 对应的图案候选、`body_world_raw.npz` 的固定相机内参，以及 `data/ollie/common_world.json` 的固定相机到共同世界变换。世界采用米制、Z 向上，板初始中心约 `(0,0,0.074)` 米。没有把人体前端逐帧反算的外参当成相机运动。

当前显式假设为：中间图案长 0.21 米、宽 0.18 米，整板长 0.8013 米、宽 0.21 米；中段板面位于板根上方 0.006 米。这些均为工程尺寸假设，原视频未提供实测尺寸。共同世界的地面 / 相机也属于近固定相机假设，仍有小幅画面抖动。单目恢复的绝对尺度因此依赖上述假设。

每个有效图案调用 IPPE，保留两个平面姿态解，使用重投影、板面朝上、平地段高度和时间连续性选择分支；不只选最小像素误差。第 119 帧的两个像素 RMSE 约为 0.224 / 0.341；前者在共同世界中板面法向 Z 分量为负，故选择后者。OpenCV 4.12 实测需要将 IPPE 对象点放在 `z=0`，再通过 `t_root=t_plane-R*[0,0,0.006]` 补板根偏移；直接把相同平面的点写成 `z=0.006` 曾出现约 50 像素的异常误差，现已修正。

只有原始帧 114–122 共 9 帧同时通过图像置信度及姿态重投影阈值，进入完整四角三维约束。其余图案候选只约束中心；薄图案的相似变换传播不被当成可靠的透视 / 深度观测。原始帧 0–102、130–185 使用近水平地面先验，103–105 等过渡段只使用弱图像与时间约束。平地先验限制高度、roll、pitch，允许 yaw 随时间变化。

优化还使用位姿二阶平滑，以及空中中段的弱重力约束。`t_physics=t_video/1.5` 仍是未验证的时间假设，重力项不能据此证实慢放倍率。106–111、123–127 的 11 帧缺失均保留 `observed_2d=False`，最终位姿标为 `temporal_physics_completion`，不是补成了三维观测。轮转角 / 转速没有恢复，四个轮的零值是占位，带 `wheel_motion_observed=False`。

为核对图案之外的尺度和朝向，另加入原始帧 119、128、185 的可见圆头 / 圆尾近似中心点，像素不确定度分别设为 8 / 12 / 12；初帧沿用共同世界标定的板端点。人工标注输入在本机 `logs/ollie/board_reference/manual_board_landmarks.json`，并记录到输出诊断中。它们是目视工程标注，不是检测器真值；没有声称恢复了被遮挡的轮轴。

## 当前可用产物与复跑

当前推荐产物位于本机 `logs/ollie/board_reference_v3/`；同级无后缀及 `v2` 是开发中间结果。原始视频、图像与这些派生结果均在忽略目录，不进入 Git。

```bash
.cache/board-cv/bin/python scripts/video/fit_board_reference.py \
  --observations logs/ollie/board_tracking/board_image_observations.json \
  --body logs/ollie_gvhmr/ollie/body_world_raw.npz \
  --common-world data/ollie/common_world.json \
  --video video/ollie.mp4 \
  --extra-landmarks logs/ollie/board_reference/manual_board_landmarks.json \
  --out-dir logs/ollie/board_reference_v3
```

如只需审查原始候选，追加 `--candidates-only`，不会做平滑或生成完整参考。

- `raw_board_candidates.npz`：186 个原视频帧的双解相机 / 世界位姿、选解、重投影误差、原始二维置信度、缺失及是否有米制姿态支持的掩码；缺失处保留 NaN。
- `fitted_source_trajectory.npz`：源 PTS 上的平滑共同世界位姿，以及几何修正前的解。
- `board_reference_50hz.npz`：258 帧，物理时间 `0..5.14` 秒，视频时间 `0..7.71` 秒；最后一个原视频帧的 PTS 是 7.716042 秒，重采样没有把容器结束时间伪造成一帧。
- `board_reprojection_review.mp4`：原图上的板外形绿色、假设图案青色、二维候选黄色；明确标为运动学拟合。`reprojection_check.npz` 保存相同投影。
- `raw_diagnostics.json`、`fit_diagnostics.json`、`geometry_qa.json`：来源哈希、假设、缺失、人工板端和实际误差；`fit_contactsheet.jpg` 为抽帧核对图。

50 Hz 接口中 `board_qpos` 为 `[world_xyz, quaternion_wxyz]`；`board_state` 的 21 维依次为根位置 3、根四元数 4、轮角 4、根世界线速度 3、根机体系角速度 3、轮速 4。提供 `time_physics`、`time_video`、`source_frame`、`phase`、`phase_names`、`board_pose_confidence`、`foot_board_prior` 和来源标签。阶段名依次为 `prepare,crouch,pop,flight,landing,recovery`，它们是粗阶段先验，不能用于证明接触切换时刻。

`board_pose_confidence` 不是校准后的概率：完整图案支持处沿用二维置信度，其余有图像中心处用 0.35 工程值，缺失处用 0.1，重采样时线性插值。两脚接触先验仅在保守站稳范围标为 1，其余为 -1 未知，`contact_prior_is_observation=False`；下游联合 IK 应使用显式站稳时间窗，不能把阶段或这些值当成实测接触力。

## 实际核对结果与限制

本轮优化 18 次函数求值后满足 `ftol` 停止条件。完整图案支持的 9 帧，最终像素 RMSE 中位数 1.061，最大 2.973。初帧 / 第 119 帧的近似板端 RMSE 分别为 2.779 / 3.808 像素；第 128 / 185 帧仍为 17.043 / 20.370 像素。已抽查准备、起跳缺失窗、空中、落地与最终站稳的重投影；晚段残差说明图案漂移、近似相机 / 地面和尺寸假设尚有冲突，未通过硬拟合隐藏这些差异。

几何检查使用被动滑板 XML 的中心板盒、翘起板端盒以及四个轮圆柱的最低支撑点。轮采用轴向半宽与径向半径的解析支撑函数，没有把一个固定的局部轮底点旋转后当成任意姿态的最低点。源帧最大上移修正为 1.229 毫米，重采样后的最大补偿为 0.067 毫米；修正前位置和补偿均被保留。258 帧碰撞包络最低高度不小于零，板根最高约 0.610 米，最大线速度约 2.675 米 / 秒，最大角速度约 7.085 弧度 / 秒。

上述检查只说明当前假设下的几何结果。没有由此证明板的冲量、摩擦、足底接触、动量或整段轨迹动力学可行，也没有证明生成了真实 Ollie 策略。后续须在同一世界中完成足底联合校正、接触及碰撞 QA，再通过只向机器人施加控制的前向仿真验证。脚本静态检查、语法编译，以及真实输入的 186 → 258 帧运行与有限性 / 四元数 / 时轴 / 几何支撑检查已通过。
