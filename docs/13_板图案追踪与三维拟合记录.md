# Ollie 板图案追踪与三维拟合

2026-10-23。输入为 `video/ollie.mp4`，原始哈希与时间事实见文档 07。此组件用于提供人板共同重建的二维证据，不是已经恢复完成的三维参考。

## 已实现

`scripts/video/track_board.py` 读取 ffprobe 原始 PTS，用少量人工目视的板面图案四角作种子，利用 [OpenCV 光流](https://github.com/opencv/opencv/blob/5.x/doc/tutorials/others/optical_flow.markdown)与 RANSAC 传播。检查前后向误差、内点、凸性、面积与最大位移，丢失后停止该传播，不用插值冒充观测。近乎侧对镜头的准备段使用相似变换，避免薄图案的单应矩阵病态放大；图案清晰的空中 / 落地片段使用单应变换。

种子在原始帧 0、119、128，帧号从 0 开始，四角顺序为远侧尾端、远侧头端、近侧头端、近侧尾端。标注针对中部红白图案，不是板外轮廓；坐标是目视近似，受脚遮挡和透视影响，并非真值。种子数据保留在 `data/ollie/board_image_seeds.json`，不上传派生输入数据。

输出逐帧原始视频时间、`t_physics=t_video/1.5`、图案四角、置信度、种子来源、内点和缺失标记。时间倍率仍为待验证估计。

## 本机安装与调用

独立环境 `.cache/board-cv`，Python 3.12.13；固定 NumPy 2.2.6、SciPy 1.15.3、opencv-python-headless 4.12.0.88、Pillow 11.3.0。未往训练 `.venv` 注入 OpenCV。

```bash
uv venv .cache/board-cv --python 3.12
uv pip install --python .cache/board-cv/bin/python -r scripts/video/requirements-board-cv.txt
.cache/board-cv/bin/python scripts/video/track_board.py \
  --video video/ollie.mp4 --seeds data/ollie/board_image_seeds.json \
  --out-dir logs/ollie/board_tracking --slowdown 1.5
```

输出为本机 `board_image_observations.json` 与 `tracking_review.mp4`；后者仅是二维追踪核对视频，不是物理执行。脚本拒绝与源文件哈希不匹配的种子。

## 检查与边界

首版对 175 / 186 帧产生候选图案观测；11 帧缺失为 106–111 和 123–127，恰处于踩尾侧视 / 落地前遮挡等困难窗口。候选数不代表可靠恢复率，长距离传播的置信度会降低。已目视查看准备、预蹲、起跳、空中、落地和站稳抽帧。

检查发现薄图案用自由单应传播可能把形状拉长，故准备段改用相似变换并限制传播到原始帧 105。清晰腾空帧的图案仍能跟踪；接触切换关键时刻不能仅据这些点判定真接触。

下一步结合人体恢复的相机内参、地面与空间尺度拟合板姿态，并做时间连续性 / 人板关系校正。[OpenCV PnP](https://docs.opencv.org/4.12.0/d5/d1f/calib3d_solvePnP.html)估计需要正确的三维—二维点对应和相机标定；图案真实米制尺寸、遮挡以及平面姿态双解仍需处理。当前输出仍带原相机运动，不将其直接作为米制世界轨迹；缺失窗口须通过额外可见板端 / 轮轴证据或明确标注的物理先验处理。
