# Ollie 后脚与板尾接触诊断

本轮只读核查确认：现有准备段后脚主要踩在后轮轴附近，未覆盖翘尾；这会削弱压尾杠杆，但尚不能据此断言它是全部失败的唯一原因。原片动作、运动学参考和原生仿真受力分别核查，不将参考姿态的 `mj_forward` 求解力当成观测。

## 输入与坐标

- 现参考：`data/ollie/air_relative_video_timed_v1/joint_reference_50hz.npz`，SHA256 `941f748cf3b13edbcf60dd20f2db41810cee2cbd1e9b4dccba1e3b1d4b5a71f5`。
- 旧参考：`data/ollie/self_collision_corrected/joint_reference_50hz.npz`，SHA256 `f6150d1217a4cf4952c3c03e601df4abe20b649ce03abb6f6b4c208d894f8dbc`。
- 真实准备教师：`logs/ollie/air_repair/video_timed_v1/teacher_migrated_v2.npz`，SHA256 `c953f231a5d0d47ce7d850f71ddf01ba64807e5b0ec78f102a50ad86cf964a8c`。
- 板局部 X 正方向是左脚/前端，右脚为后脚。后轮轴中心 X=−0.21m；中心平板 X=[−0.28,+0.28]m；12°翘尾碰撞盒投影 X=[−0.4018926,−0.2781074]m。
- video=1.5×physics 仍为时间尺度假设，并非原片实测慢放倍率。所有力点的 X 都转换到当时真实板坐标。

## 足底包络与接触距离

使用真实 G1 每脚7个碰撞胶囊，求精确轴向投影范围、沿板法向最低支持点，另以 MuJoCo `mj_geomDistance` 求胶囊到中心板/翘尾的最短有符号距离。脚 site 仅为语义位置，不代表完整足底。

准备 phys2.60..2.76s，右脚 site 约 X=−0.2071m；phys2.76时全部胶囊 X 包络为[−0.2453,−0.1638]m，与翘尾 X 范围不相交。到中心板最短距离0.801mm，到翘尾34.422mm。现参考和旧参考在该前缀逐值一致，因此此结论同时适用。

当前参考离开准备段后没有压尾支持目标：phys2.90右脚到中心板46.534mm、翘尾60.590mm；phys3.00分别60.089mm、93.921mm；phys3.12分别247.384mm、286.535mm。这些是运动学间距，不是仿真接触力。旧参考在3.06后虽出现 X 更靠后，侧偏和穿板问题很大，不能因 X 靠尾就称成功接触。

## 锚点来源：X限幅没有触发

逐项复算原 `contact_ik.py` 的关节平滑、root calibration、各明确站立段的中位数锚点：准备左脚原中位数 X=+0.2050207304，右脚−0.2072038970；与保存锚点一致。`stance_half_length=.27` 在所有四个左右脚/准备恢复锚点的 X 方向改变量都严格为0。

所以不能把本例归因于“±.27限制把尾脚裁回中段”。中位数锚点自身就在轮轴附近；GMR缩放、单目人板共坐标误差及整段固定脚锚点共同形成当前布局。原始 GMR feet 也并未可靠落到板上，不能直接当成正确尾部接触证据。当前空中相对修复保留腿角，只改根和板高，也没有恢复压尾动作。

## 真实教师的上表面受力点

以原始初态和保存的138组29维PD目标，原生CPU MuJoCo3.16.0连续重放，8×2.5ms子步，无中途state写入或重置。139帧 qpos/qvel 与1104帧 state92最大误差均严格0，施加外力全0。

采用共享 `ContactObserver` 的有符号上表面筛选：仅中心板/尾/鼻上面，法向确实向脚，局部接触Z≥0，法向力>1N。不是把底面或轮轴碰撞当支撑。所得结果：

- 整段0..2.76s：右脚受力加权 COP X=−0.216683m，全部在中心板，翘尾承载比例0；右脚法向支持中53.08%位于后轴后方。
- 最后2.60..2.76s：右脚 COP X=−0.198296m，在后轴前11.704mm；仅11.87%的右脚支持位于后轴后方，翘尾承载仍0。左脚 COP X=+0.234971m。
- 上述比例由支持力积分加权，不是接触点计数比例。准备教师到2.76s结束，不能把这些力点推断为原视频或起跳段的实测接触力。

后脚全部没有踩上翘尾，且准备末端主要载荷在轴前，确实不利于产生需要的压尾力矩；仍须用接触动力学和连续控制试验检验新布局能否改善起跳。

## 原片证据与窗口不确定性

抽取原始186帧视频的104、106、108、110、112帧，原PTS分别4.337667、4.421083、4.504500、4.587917、4.671333s，未改变原视频。裁剪只用于看清鞋底与板边。

104帧右后鞋位于画面左侧翘尾附近，鞋位于后轮轴后方；106帧仍接近尾面；108帧鞋底与尾端已明显分开，随后后脚抬起。单帧透视/鞋底遮挡无法恢复精确3D压力点或接触力，不能把像素位置换算为已测准的−0.31m。可将 phys≤2.90s列为保守工程压尾候选，2.90..2.94s作为边界敏感性测试，之后保持未知/释放。

## 后续修复约束

建议另建参考分支：右脚准备锚点 X约−0.30..−0.32m、左脚保留+0.205m；用真实12°尾面和完整足胶囊做IK，不用平板Z=.006替代翘尾。保持板全部state、姿态与9个可靠PnP节点不变，保持已修复的手臂，限制真实关节范围、12rad/s和全身几何穿透。源视频只支持这一工程接触先验，不能声称接触力已由视频测量。

新参考将改变准备段，因此旧教师/BC provenance不能不经迁移重验就复用。即使运动学质量通过，也须另外生成真实物理教师并验收，不能称作Ollie成功。
